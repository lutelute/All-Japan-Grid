# プロジェクト評価と改善計画 — Fable 5 判断記録

- **日付**: 2026-06-10 / **モデル**: Claude Fable 5 / **HEAD**: 928ce94 時点
- **契機**: ユーザー評価「特に潮流計算とか系統の点と線を接続するのが弱い」
- **方法**: 3並列監査（トポロジ接続 / 潮流電気モデル / パイプライン構造）+ 現物コード裏取り + 公開データ実測

## 総評

器（DB機械更新ループ・CIM/CGMES・来歴管理・`ajgrid` CLI・テスト901本）は良い。
電気モデルとしての中身が弱い。ユーザー診断は正確で、さらに**両者は独立の弱点ではなく、
接続の弱さが潮流の弱さの根本原因**という構造であることを確認した。

## 弱点1: 点と線の接続

**実測: 公開データの合成線率**（reconnectorが幾何で繋げず人工生成した線の割合）

| 地域 | 合成線/全線 | 割合 |
|---|---|---|
| 関西 | 311/2,125 | **14.6%** |
| 九州 | 157/1,663 | 9.4% |
| 中国 | 137/1,530 | 9.0% |
| 中部 | 225/3,449 | 6.5% |
| 東京 | 210/3,604 | 5.8% |

n_components=1 は接続問題の解決ではなく合成線による埋め合わせ。合成線が最多の関西が
唯一 x0.3〜0.4 需要スケールでしかAC収束しない — 接続の弱さ→潮流の弱さの直接証拠。

構造的原因:
1. **接続判定が幾何のみ**: snap_km=1.5固定・頂点一致4桁(~11m)。変電所密度の地域差を無視
2. **変電所に電圧構造がない**: 変圧器は線の両端電圧差からのみ生成。実物の多電圧母線+
   変電所内変圧器が未モデル → 電圧比20の病的変圧器 → Ybus悪条件（west AC非収束の真因）
3. **OSMタグ未活用**: `circuits`（並行回線数の直接証拠、46〜60%充足）`cables` `busbar` `ref` を不使用
4. **検証ゼロ**: 外部正解との照合なし。トポロジ回帰テストは沖縄スモーク1本のみ
5. **ビルダー分裂**: legacy / snapped / export独自実装 / CIM-L2インライン再実装

## 弱点2: 潮流計算

1. **R/X/B 100%合成**（電圧クラス典型値×距離、`config/line_types.yaml`）。実測値ゼロ
2. **負荷配分が恣意的**: OCCTOピーク×0.85を `voltage_weights`（手置きの重み）で比例配分。
   空間情報（人口等）不使用・時間断面なし
3. **発電機が裸**: QMIN/QMAX なし・vm_pu=1.0固定・AVRなし
4. **収束の便宜が積層**: 角度閾値枝削除 / 需要スケールladder / 電圧スナップ / ゼロ電圧補完 /
   容量事後拡大 / 6段ソルバーフォールバック。個別には開示済みだが複合すると物理的意味が失われる
5. **外部検証ゼロ**: OCCTO連系線潮流実績との比較なし
6. **パイプライン4分裂**: 地域pandapower / 全国ゾーナル / MATPOWER / CIM-L2

## 改善計画（ユーザー承認済み: 「順に全部」）

| # | 内容 | 狙い |
|---|---|---|
| ① | **検証フレームワーク**: トポロジKPI+合成線率+回帰pin+外部照合の器 | 物差しを先に作る。以後の改善を数値で証明 |

計測で確定した新事実:
- 四国はビルダー段階で56成分・最大成分カバー57%・電圧不明枝32%（公開ページの見かけより悪い）
- okinawa solved n_components=4 は離島の実分離。>5km海峡を捏造しない現行設計は正直で維持すべき
- `circuits` タグが半数で充足 — ④で取り込めば並行回線推定を幾何推測から証拠ベースへ移せる

## 限界の明記（誇張防止）

- 本評価のKPIは「OSMという入力の範囲での品質」を測る。入力自体の欠落（OSM未記載の線）は
  外部照合（送配電事業者の公開系統図・空容量マップ等）が入るまで定量化できない
- ②の縮約は下位網の物理を消す操作であり、AC収束は「基幹系統モデルとしての収束」。
  全電圧階級のAC級モデルには権威パラメータ（Pillar 3）が引き続き律速
