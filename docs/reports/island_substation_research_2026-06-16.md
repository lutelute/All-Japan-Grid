## 方法と判定基準

1. **一次根拠 = OSM タグ**: 各島エントリを名称(正規化)で `data/<region>_substations*.geojson` の OSM フィーチャに突合(824/855 が名称一致)。OSM の `substation`(transmission/distribution/traction/...)・`operator`・`voltage`・`frequency_conversion` を判定の一次根拠とした。
2. **上位60件(高電圧優先)は個別 Web 検索で検証**(電力会社公式PDF・Wikipedia・JR/鉄道会社・自治体)。検証済みは表の根拠欄に [verified] を付す。
3. **判定基準(オーナー精緻化方針 2026-06-16 反映)**:
   - **A(要連系=繋ぐ)**: **公称 ≥66kV(特に ≥154kV)** で送電網へ高圧送電線で繋がる/繋がるべきもの。発電所側・自家用・風力集電・水力開閉所・クロス事業者(関西の木曽川水系資産等)も**物理的に繋がるなら A**。OSM で島なのは連系線データ欠落のため。
   - **B(除外)**: **鉄道き電用**(電車線・別系統)、**<66kV の配電用**変電所、または高圧でも真にどこにも繋がらない孤立自家用に限る。
   - **?(不明)**: kv=0 かつ OSM 種別タグ無し・運営者不明で、配電/鉄道いずれとも確定できないもの(配電寄りと推定)。
4. **接続先候補**列: 各 A エントリについて、ローカルの変電所データから**最寄りの別名称グリッドノード**を機械的に算出した**推定候補**(<8km)。確証ではない。
5. **捏造厳禁**: 確実な情報源が無いものは「推定」明記または「不明」。名称・座標は名寄せの手がかりに使用。

> **重要な既知のデータ品質問題**: 入力の `region` タグは実県と矛盾する例が多数(例: 下北半島の青森県変電所が `hokkaido`、広島・山口県の中国電力220/110kV変電所群が `shikoku`、長野県木曽の中部/関西資産が `hokuriku`、群馬・栃木のTEPCO資産が `tohoku`/`chubu`)。近接リージョンへの取り込み誤り。また `220kV` 等の電圧ラベルが OSM 実値(`voltage=110000`)と食い違う例あり(黒瀬・廿日市等)。本レポートは OSM 実タグを優先した。

### 2. 残り「?」189件(kv=0)の効率調査
- いずれも kv=0・OSM 種別タグ無し。**市街地名+「丁目/条丁目」**のものは配電用がほぼ確実 → まとめて B 推定でよい。

### 3. データ品質の是正提案(分類より上流)
- **region 誤タグの是正**: 下北半島群(青森)が `hokkaido`、広島・山口の中国電力220/110kV群が `shikoku`、木曽(長野)が `hokuriku`、群馬・栃木のTEPCO資産が `tohoku`/`chubu`。実県・実TDOへ再マッピングすれば、地方別の連系欠落集計が正確になる。
- **電圧ラベル是正**: 「220kV」表記だが OSM 実値 `voltage=110000` の例(黒瀬・廿日市・呉・宮原・向島 等、中国電力管内に多数)。モデルの kv フィールドを OSM `voltage` で上書き校正すべき。
- **接続先候補**列は最寄りノードの機械推定。実際の連系は OSM の `power=line` 端点追跡(同電圧・同事業者)で確定すべき。

### 4. 再接続の優先順位(A 397件)
1. **≥154kV(65件)**: 基幹送電の連系欠落。最優先(東京都心275kV地中網10件、中国電力220/110kV島嶼網、下北半島154kV、木曽川水系154kV 等)。
2. **110kV(52件)**: 中国電力ネットワーク管内の一次変電が中心。
3. **66-77kV(280件)**: 二次変電。数は多いが、deg≥1(既に一部接続)のものは連系線1本の欠落である可能性が高く、復旧効果が高い。

### 5. 注意(本分類の限界)
- HV方針により、OSMで `distribution` タグの 66-110kV 変電所(146件)も A とした。これらは厳密には**一次/二次変電所**で送電網の末端だが、オーナー方針(高圧は繋ぐ)に従う。純粋な低圧配電(<66kV)とは区別済み。
- 発電所開閉所・交直変換所(阿南FC・由良開閉所・新信濃FC 等)も「物理的に基幹へ繋がる」ため A としたが、潮流計算上は電源/変換ノードとして特別扱いが必要。
- 個別検証は上位60件のみ。61位以下の A/B は OSMタグ+電圧ヒューリスティックで、確度 mid/low を付している。
