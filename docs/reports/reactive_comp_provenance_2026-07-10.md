# 介入#20「無効電力の局所補償」 補償率 factor=0.6 の一次資料調査

- 調査日: 2026-07-10
- 対象: 介入#20（`--reactive-comp`）で負荷バスへ容量性シャント（配電用変電所のコンデンサバンク/SVC相当）を付与する際の補償率 `factor`。現状 0.6 は「中央値設定・実測値ではない」（`docs/MODEL_INTERVENTIONS.md` #20、`docs/reports/east_network_reactive_2026-07-09.md` §6）。
- 目的: `factor` を「負荷（または負荷の無効需要）に対する補償容量の比率」で裏付けられる一次資料（官公庁・事業者・学会・統計）を探す。
- 誠実性ルール: 採用候補は必ず URL + 原文逐語引用つき。引用が取れない値は「候補外」。二次資料（ブログ・まとめ）は不可。

---

## 0. 結論（要約）

- **一次資料で "factor=X" とそのまま書かれた値は存在しない**（当然。factor はモデル固有の量）。ただし **factor に換算可能な一次データ**は見つかった。最有力は四国電力送配電が電力・ガス取引監視等委員会（EGC）WGに提出した設備実績グラフ。
- **最有力アンカー（Source A・四国EGC 2024）から換算すると、現在の系統では factor ≈ 0.8**（送電端の遅相無効電力が最大電力の~7%まで低下＝送電端力率 ≈ 0.998）。**1990年代は factor ≈ 0.05**（送電端力率 ≈ 0.95）だった。つまり factor は数十年かけて 0→0.8 へ漂移してきた。
- **現行の 0.6 は「歴史的レンジ内の中間〜やや保守側」**の妥当な値（送電端力率 0.991 相当）。ただし**直近実測に合わせるなら 0.8 の方が支持される**。0.6 は現在基準ではやや過小補償（送電網に無効電力を多めに残す）側。
- **全国単一値としての factor は、無料公開の一次資料だけでは確定できない**。理由: (a) 電気事業便覧の全国 調相設備容量は「設備容量（設置kvar）」であって「ピーク時の運用残差無効電力」とは別量、かつSC（コンデンサ）とShR（リアクトル）が混在。(b) ピーク時の運用残差無効電力（＝factorに直結）を系統単位で公表しているのは四国EGCのような散発事例のみ。
- **推奨**: Source A を一次アンカーとして引用し、factor を **0.6–0.8 のレンジ**（0.6=保守/中間、0.8=直近実測整合）として提示、換算式と仮定を台帳に明記する。単一決め打ちにするなら、直近実測整合の観点では 0.8 に上げる根拠がある。他TSOの同種EGC提出資料（東北・関西等）を集めればマルチ事業者アンカーに強化できる。

### Source A（最有力・定量換算可）— 四国電力送配電「調相設備見直し」EGC提出資料
- 種別: **一次資料**（一般送配電事業者が経産省・電力ガス取引監視等委員会「送配電効率化・計画進捗確認WG」へ提出）
- 出典: 四国電力送配電株式会社「第6回 送配電効率化・計画進捗確認WG ミクロ検証 説明資料（調相設備見直し）」資料5-3、2024年8月26日

**逐語引用（p.1「調相設備の概要」）**:
> 「調相設備は、電圧を適正な範囲に維持することを目的とした設備であり、系統に接続し無効電力を調整することで、電圧を上げたり、逆に下げたりすることができます。」
> 「調相設備には、電力用コンデンサ（ＳＣ）、分路リアクトル（ＳｈＲ）などの種類があります。」

**逐語引用（p.4「（参考）電力用コンデンサの設置状況」）**:
> 「電力需要の動向等を踏まえ、2000年頃までは電力用コンデンサの新設・増容量化を実施してきており、1970〜1980年頃に大量に設置された電力用コンデンサが更新時期を迎えることとなります。」

グラフ注記（p.4、期間ラベル・逐語）:
> 左期間「遅相無効電力が増加　ＳＣの新設・増容量化」／ 右期間「遅相無効電力が漸減　ＳＣの設置数は変化なし」

**p.4 グラフの数値読み取り（四国系統・1973–2023、目視読み。誤差±10–15%）**:
- 軸: 左＝台数(0–8)／遅相無効電力[Mvar](100–2100)、右＝最大電力[MW](0–7000)。
- 系列: `最大電力実績`（緑・MW軸）、`遅相無効電力実績`（青・Mvar軸）、`SC台数`（棒）。
- **最大電力実績（直近2020年代）: ≈ 5,000–5,200 MW**（ピークは2005年頃 ≈ 5,900–6,000 MW）。
- **遅相無効電力実績（直近2020年代）: ≈ 300–400 Mvar**。
- **遅相無効電力実績（1990年代後半ピーク）: ≈ 1,400–1,500 Mvar**。

補足（同資料の確定数値・逐語）:
- p.5 例示のコンデンサバンク単機容量「20Mvar」「10Mvar」（変電所SC容量の桁感）。
- p.7 効率化計画物量「調相設備の見直し（うちミクロ検証対象）　▲20台（▲2台）」「▲228百万円（▲44百万円）」。

**この資料が factor に効く理由**: `遅相無効電力実績` は「顧客側・配電側の局所補償（コンデンサ）を差し引いた後に、送電系統（＝発電機側）が実際に運ぶ遅れ無効電力」に相当する。これはモデルの残差 (1−factor)·Q_load とちょうど同じ量。→ §2で換算。

### Source B'（学会誌・Source Bの要約）— 電気設備学会誌 2011年9月号
- 種別: **学会（一次）**（電気設備学会誌の講習会報告。Source Bの内容を学会員向けに紹介）
- 出典: 「配電系統の力率問題と高圧需要家の進相コンデンサに関する取組み」電気設備学会誌 J. IEIE Jpn. Vol.31 No.9, 2011年9月, pp.742–743（中部支部だより）
- URL: https://www.jstage.jst.go.jp/article/ieiej/31/9/31_742/_pdf

**逐語引用（p.742）**:
> 「実態調査によると，高圧配電系統は恒常的に進み力率となっており，低圧配電系統は遅れ力率になっている。」
> 「測定結果をもとにシミュレーションによる解析を行った結果，配電系統の約2/3でフェランチ効果が発生し，配電用変電所変圧器ではタップ極限状態が約7%発生し，配電系統の電圧適正維持が困難化してきている。また，無効電流による電力損失は全電力の1割程度もある。」
> 「調査した需要家では，進相コンデンサを三相変圧器容量の1/3で設置されている事例が多い。」

**逐語引用（p.743）**:
> 「①高圧受電設備の設計の実態は，75%の設計会社が進相コンデンサ容量を三相変圧器容量の1/3で設計する手法を用いている。」
> 「①進相コンデンサは，一般的に三相変圧器容量の1/3程度で選定しているが，実際の負荷容量は三相変圧器容量より少ないことや，負荷力率を80%程度で進相コンデンサの容量を選定しているのに対して，実際の負荷力率は90%程度であること。」
> 「力率適正化の対策は，進相コンデンサ容量の選定を三相変圧器容量の1/3で行わず，負荷の無効電力を想定して設計することや，進相コンデンサを分割し，APFCにより制御することが必要である。」

**factor への含意**: 日本の高圧配電は「恒常的に進み力率」＝負荷の無効需要は顧客側コンデンサで**過剰なほど**局所補償されている。これは「送電系統が運ぶ残差無効電力が小さい＝実効 factor が高い（1に近い、局所的には超過）」ことの全国的裏づけ。Source A の四国の傾向が全国的現象であることを支持する。

- 種別: **一次資料**（規制上の託送約款）
- 出典: 東京電力パワーグリッド株式会社「託送供給等約款」令和6年4月1日実施
- URL: https://www.tepco.co.jp/pg/consignment/notification/pdf/takusou_yakkan20240117.pdf

**逐語引用（力率割引・割増、基準力率）**:
> 「力率が，85パーセントを上回る場合は，その上回る１パーセントにつき，基本料金（…）を１パーセント割引し，85パーセントを下回る場合は，その下回る１パーセントにつき，基本料金（…）を１パーセント割増しいたします。」
> 「まったく電気を使用しないその１月の力率は，85パーセントとみなします。」

**逐語引用（力率の保持）**:
> 「接続供給における供給地点ごとの力率は，原則として，電灯…については90パーセント以上，その他の供給地点については85パーセント以上に保持していただきます。」
> 「（高圧または特別高圧で供給する場合）接続供給における供給地点ごとの力率は，原則として85パーセント以上に保持していただきます。なお，軽負荷時には進み力率とならないようにしていただきます。」

**factor への含意**: 需要家の受電端力率は制度上 **85%以上に保持**（軽負荷時は進み力率禁止）。つまり負荷は受電端で最低でも 0.85 遅れ、実務上は固定コンデンサで概ね1.0付近〜進み側まで補償される。モデルの「負荷 pf=0.95」は 0.85（制度下限）と1.0（過補償）の中間の妥当な代表値。約款は別表12「進相用コンデンサ取付容量基準」も持つが、これは器具別μF基準（けい光灯・水銀灯等）で系統補償率ではない（factor 換算には不向き）。

## 2. factor への換算（Source A を用いる）

モデルは各負荷バスを pf=0.95 で表現する（east: P=57,403 MW / Q_load=18,868 Mvar → tanφ=0.3287 → pf=0.95。`east_network_reactive_2026-07-09.md`）。
補償は容量性シャント `factor·Q_load` を負荷バスに置き、送電網に残る遅れ無効電力は `(1−factor)·Q_load`。

**換算式**:

    factor ≈ 1 − Q_grid,peak / ( P_peak · tan(arccos(0.95)) )
    ただし tan(arccos(0.95)) = 0.3287

**Source A（四国）を代入**:

| 断面 | P_peak [MW] | Q_grid,peak（遅相無効電力実績）[Mvar] | Q_load=0.3287·P [Mvar] | → factor | 送電端力率 |
|---|---|---|---|---|---|
| 2020年代（直近） | ~5,100 | ~350（300–400） | ~1,676 | **≈ 0.79（0.76–0.82）** | ≈ 0.998 |
| 1990年代後半 | ~4,800 | ~1,500 | ~1,578 | **≈ 0.05** | ≈ 0.95 |

- **直近実測 → factor ≈ 0.8**。1990年代 → factor ≈ 0.05。factor は数十年で 0→0.8 へ漂移（＝顧客側の進み力率化が進行、Source B' の「恒常的に進み力率」と整合）。
- **現行 factor=0.6 の位置**: 送電網残差 = 0.4·18,868 = 7,547 Mvar（east）／四国相当なら 0.4·1,676 = 670 Mvar。送電端力率 = cos(arctan(0.4·0.3287)) = **0.991**。→ 1990年代(0.95)と直近(0.998)の**中間**（2000年代半ば相当の補償水準）。

**east 全島を直近実測(送電端力率0.998)に合わせる場合の factor**:

    残差 = 57,403 · tan(arccos(0.998)) = 57,403 · 0.0633 ≈ 3,634 Mvar
    factor = 1 − 3,634 / 18,868 ≈ 0.807 → ≈ 0.8

四国換算と一致。

### 換算に置いた仮定（明記）
1. **負荷を pf=0.95 で定義**（モデルの現行仮定）。もし「補償前の真の負荷力率」を制度下限 0.85 と採るなら Q_load はより大きく、実測整合の factor はさらに高くなる。
2. **`遅相無効電力実績` = 補償後に送電系統が運ぶ残差**（＝(1−factor)·Q_load）とみなす。これは調相設備が需要家/配電側で局所補償するという Source A/B の描像に沿う標準解釈。
3. **グラフ目視読み取り**（Mvar/MW軸）につき値は±10–15%の不確かさ。
4. **単一事業者（四国）**の断面。Source B（電気協同研究・全国）が「進み力率は全国的現象」と示すため傾向は代表的だが、比率の絶対値は事業者ごとに異なりうる。
5. 四国系統全体の集計値をモデルのバス別 pf 仮定に対応づけている（空間分布の違いは無視）。

## 3. 見つからなかったもの（負の結果も記録）

- **電気事業便覧の全国 調相設備容量（kvar）数値**: 便覧には「調相設備容量」欄が存在すると推定されるが、無料公開範囲では数表を取得できず（冊子/有料）。**かつ設備容量（設置kvar）は factor（運用時の残差比）とは別量**で、SC（進相）とShR（遅相吸収）が混在するため単純換算は不可 → 候補外。
- **電力調査統計（資源エネ庁）**: 発電量・需要・燃料が中心。変電・調相設備容量の統計表は確認できず → 該当なし。
- **EGC マクロ検証資料（0007_03_00.pdf, 2024-11-25「その他の送変配設備」全国集計）**: 「リアクトル・コンデンサ」は投資額（億円）ベースのコスト内訳に出るのみで、全国の調相設備**容量[Mvar]や運用無効電力**は載っていない → factor アンカーには使えず。
- **OCCTO 供給計画/広域系統整備計画の調相設備量**: 力率設定（発電側0.95）は取得したが、負荷の局所補償容量の全国値は未取得。

## 4. 推奨

1. **一次アンカーとして Source A（四国EGC 2024, URL上記）を採用**し、§2の換算式と仮定を介入台帳#20に添える。
2. **factor は 0.6–0.8 のレンジで扱う**:
   - `0.6` = 保守/中間値（送電端力率0.991、歴史的レンジ内）。現行維持は不当ではない。
   - `0.8` = **直近実測整合**（送電端力率≈0.998、四国EGC直近断面）。「現在の系統を再現する」目的なら 0.8 の方が一次資料の支持が強い。
3. **単一決め打ちにするなら**: 論文/モデルが「現代の系統断面」を標榜するなら factor を **0.6→0.8 へ引き上げる**根拠がある。ただし過電圧外れ値（`east_network_reactive_2026-07-09.md` の vm_max≈1.70）への影響は補償率非依存の局所アーティファクトと診断済みなので、引き上げの副作用は小さい見込み（要再スイープ確認）。
4. **強化策（任意）**: 東北・関西等の他TSOが同じ「送配電効率化WG」に提出したミクロ検証（調相設備）資料を集め、各社の `最大電力 vs 遅相無効電力` からマルチ事業者の factor 分布を作れば、全国代表値に格上げできる（EGC 0006/0007/0008/0009 回の配布資料一覧が入口）。
5. **誠実性**: いずれにせよ factor は「実在設備（配電用コンデンサ）の集約モデル化」であって単一の公表実測値ではない。台帳#20の「中央値設定・実測値ではない」注記は、上記換算（0.6は0.998実測より保守側）を添えて残すのが正確。
