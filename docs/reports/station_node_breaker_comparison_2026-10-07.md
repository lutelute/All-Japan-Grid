# SubSLD と node-breaker 方式の比較 — 日本の 7,239 変電所で（2026-10-07）

All-AU-Grid がまとめた変電所の構内結線の方法（node ID で結ぶ node-breaker）を、All-EU-Grid が欧州全体に実装した（All-EU-Grid の `docs/STATIONS.md`）。
その実装を日本の OSM にかけ、本リポジトリの SubSLD（GridStitch P2、`docs/SUBSLD_METHOD.md`、`data/structures/*.json`）と同じ変電所ごとに比べた。
サイトごとの結果は [`station_node_breaker_comparison_2026-10-07.csv`](station_node_breaker_comparison_2026-10-07.csv)。

## 入力

| | SubSLD | node-breaker |
|---|---|---|
| OSM | 地域別 Overpass の GeoJSON（構造 DB は 2026-07-02 生成） | Geofabrik `japan-latest.osm.pbf`（2026-10-06T20:21:06Z、md5 `99b99e4c…`）を `osmium tags-filter nwr/power r/route=power` で絞ったもの |
| 結線の根拠 | 座標を小数 6 桁に丸めた頂点 | OSM の node ID |
| 実装 | `scripts/build_substation_structure.py` `extract_structure` | All-EU-Grid `src/all_eu_grid/stations.py` + `station_views.py`（All-AU-Grid の規則 + 欧州で足した 5 規則） |

構造 DB の 7,239 サイトすべてが、`<region>_substations.geojson` の重心と名前を通じて OSM の変電所に対応した（未対応 0）。
観測の時点が 3 か月違うので、件数はサイトごとの比較であり、同じデータとは言わない。比較スクリプトは All-EU-Grid の `scripts/station_compare_japan.py`。

## 全体

| | SubSLD | node-breaker |
|---|---:|---:|
| 母線 | 2,559（頂点の塊）+ 推定 2,669（`bb-inferred`） | 接続点 1,459、区間 2,869 |
| 開閉器 | ベイからの推定 8,386 | OSM の実物 1,882 |
| 変圧器 | 電圧の梯子 2,586 | OSM の実機 2,613（両側の巻線電圧が分かる 1,692） |
| 線路の端 | 頂点共有 7,930 / 敷地内 13,626 / 引込帯 0.6 km 26,423 | 構内配線に接続 5,811 / 敷地内で終端 4,674 / 線路同士 1,020 / 通過 2,154 |

## 1. 変圧器: 梯子は 18% の変電所で OSM の実機と食い違う

OSM が両側の巻線電圧付きで変圧器を描いている 594 か所で、実機の電圧の組と梯子の組を比べた。
比べる単位は本リポジトリの `_vclasses` と同じ kV の切り捨て整数（6.6 kV は 6）。

| 判定 | 箇所 | 割合 |
|---|---:|---:|
| 梯子と同じ | 423 | 71% |
| OSM が梯子の一部しか描いていない | 65 | 11% |
| 梯子に無い組の実機がある | 106 | 18% |

食い違い 106 か所のうち 47 か所は、**梯子が段を飛ばす実機を見落としている**。たとえば次の所。
- 西濃・東清水・駿遠: 275/77 kV の直結（梯子は 275/154 と 154/77）
- 東岡山: 500/110 kV
- 安瀬: 66/6 kV（梯子は 66/22 と 22/6）

残りは、構造 DB が階級として持たない電圧（6 kV など）への変圧器である。梯子はトポロジ（どの階級が直接つながるか）を誤らせうる。
実機のある変電所では、実機の組を優先するのがよい。

## 2. 構内の帰属: 母線・ベイの 23〜25% を、隣の変電所と二重に数えている

`extract_structure` は、敷地の外接矩形を `_PAD_DEG = 0.01`（約 1 km）広げた範囲の母線・ベイを、多角形に入っているかを確かめずに全部その変電所のものにする（`_collect_ways`）。
構造 DB を数え直すと、次の通りだった。地域境界の重複（同じ名前・位置の同じ変電所）は除いてある。
- 母線 2,530 本のうち 631 本（25%）が、2 つ以上の別の変電所に入っている
- ベイ 7,929 本のうち 1,850 本（23%）が、2 つ以上の別の変電所に入っている

例: 曲路東一丁目変電所と北方開閉所（0.6 km 離れた別の変電所）が同じ母線・ベイを共有している。
node-breaker 方式は多角形の包含（入れ子は最内側、部分重複は未確定）で帰属を決め、この重複は起きない。
SubSLD を残すとしても、`_collect_ways` の後に敷地への包含の判定を入れるべきである。

## 3. 線路の端: 55% が引込帯 0.6 km

SubSLD の端子 47,979 のうち 26,423（55%）が `leadin`、つまり敷地の外 0.6 km 以内の線の端である。近くを通る別の線を拾う弱い根拠で、SUBSLD_METHOD.md にも「要検証」とある。
node-breaker 方式は引込帯を端子にしない。代わりに次の 2 つで扱う。
- 線路の節点が柵外 25 m 以内なら帰属を認める。ただし、構内の配線や機器と共有する節点（門型鉄構）に限る。
- 敷地を横切る線路は「通過」と明示する。

## 4. 電圧の読み方

- `scripts/substation_scope.py` の `_vclasses` は、小数点を捨てて数字だけをつなぐ。`voltage=66000.0` が 660 kV、`22000.5` が 220 kV になる。
  今の日本の OSM に該当するタグは無かった（潜在の不具合）。`float` で読んで 1000 で割るべきである。
- kV の切り捨て整数なので、6.6 kV と 6 kV が同じ階級になる。
- `_primary_kv` は 1 本の線を最高電圧の 1 つに丸める。共架の線（`voltage=154000;66000`）の下位の電圧が落ちる。node-breaker 方式は電圧ごとに別の導体にする。

## 5. 開閉器と母線

- 構造 DB の開閉器 8,386 は、ベイから推した開閉点で、母線連絡は常時開を既定にしている。OSM に描かれた実物は 1,882 台で、node-breaker 方式は開閉状態を不明のままにする。
- SubSLD の母線は、頂点でつながる母線の塊で、開閉器で切らない。node-breaker 方式は開閉器の腕で区間に分ける。
  ただし、母線の分岐点に描かれた断路器（二重母線の母線断路器）では母線を切らない。

## 判定と移行

データ層は node-breaker 方式が上である。SubSLD の次の 4 つは、いずれも観測ではない。
- 変圧器（梯子）
- 開閉器（ベイから推定）
- 母線の帰属（矩形 +1 km）
- 端子の過半（引込帯）

SubSLD に残る価値は、図法（GeoPane × SLDPane）、計算モデルとの照合の発想、座標の近さを手がかりにする発想である。All-EU-Grid は、この 2 つを node-breaker の行の上に移した。
- 単線結線図の自動配置
- 全閉仮定の接続点で、描かれた構内どうしがつながらない階級を出す
- 実機の変圧器の電圧の組と、モデルの推定を突き合わせる
- 全閉でもつながらない構内の部分どうしの距離を測る（座標の近さは自動でつながず、描き漏れの候補の一覧にする）
  - 欧州で、母線の描かれた HV 階級の分裂 1,406 のうち、部分どうしが 1 m 未満なのは 83
  - SubSLD の 0.1 m の丸めで自動的につながるのは、0.1 m 未満の所だけ

移行は All-AU-Grid の `docs/JAPAN_STATION_MIGRATION.md` の順序でよい。そこで最初の障害とされた「GeoJSON に node ID が無い」は、Geofabrik の日本 PBF から取り直せば消える。
今回、日本全体を 1 回で読み、7,239 構造すべてに対応が付いた。

1. 日本 PBF を電力だけに絞る（9.5 MB、32 秒）。地域タイルの重複（落とし穴①）も起きない。
2. コア（`stations.py` / `station_views.py`、国別の電圧表は不要）を通す。既存の構造 DB の ID とはサイトの OSM キーで対応付け、ID は一括置換しない。
3. 梯子の変圧器は `structural_hypothesis` として残し、実機のある変電所では実機の組を優先する。上の 106 か所が最初の確認対象。
4. SubSLD の図は、同じ行から描く。
