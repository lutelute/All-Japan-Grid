# 敷地と線端を残す接続モデルの比較

`index.html` をブラウザで開く。全27組の元モデル・単純同定・敷地と端子を分けた第三案を比較できる。航空写真・元属性・目視所見・回路検証・試行錯誤を収録。詳細は [REVIEW.md](REVIEW.md)。

航空写真を含めてオフライン閲覧できるよう、このフォルダ全体（`basemap/`を含む）を一緒に置く。外部ライブラリ不要。スライド比較へのリンクは、隣の `codex_before_after_2026-09-12` がある場合に開ける。

正典には未適用。13組の単純同定のあと、航空写真から5組を再追跡へ戻した。第三案は同じ接続仮説を使い、設備の表示位置と計算回路を分離できることを検証したもの。

航空写真・撮影期間データ：国土地理院（https://maps.gsi.go.jp/development/ichiran.html）。敷地・線形：© OpenStreetMap contributors。画像は地理院写真にOSM敷地とモデル線を重ねた加工表示。撮影期間はHTMLに明記し、取得日とは区別する。
