# 読み方ガイド: 系統強度マップ・長軸振動地図・Ybus — 何が見えて、どう示すか

オーナー質問「見方や解析の仕方、これがどうすごいのかの示し方がわからない」への解説(2026-08-17)。
発表・論文・講義で再利用する前提で書く。

## 1. 三枚の図は「系統の別の顔」

| 図 | 物理的意味 | 直感 |
|---|---|---|
| 系統強度マップ | 各バスの短絡容量 S_sc = V²/Zth | 「コンセントの奥にどれだけ大きな発電機群が控えているか」。緑=硬い・赤=柔らかい。66kVで1〜2GVAが normal |
| 長軸振動地図 | 最低inter-areaモードのモード形 | 発電機=振り子、送電線=バネ。赤群と青群が逆位相でシーソー。west 0.434Hz=九州⇔中部関西が周期2.3秒で揺れ合う |
| Ybus(数値/spy) | バネ定数の行列(アドミタンス) | 上2枚の土台。様式5照合(比中央値1.22)が「公表値との答え合わせ」 |

## 2. 解析として何に使えるか(実務の問いとの対応)

- **強度マップ → 連系可否**: SCR = S_sc / インバータ連系容量。経験則 SCR<3 が不安定リスク帯
  (IEEE 1204系の知見)。赤いエリア×FIT集中の重ね合わせ=ホスティング容量・GFM配置の優先地図。
- **振動地図 → 制動設計と運用限界**: モード形の大きい発電機にPSS/GFMを置くのが定石。
  長軸振動の減衰が連系線の運用限界を決める(1996年米WSCC大停電がこの型の教科書事例)。
- **Ybus → すべての土台**: 短絡・潮流・動揺・(次段)Z(jω)受動性/ナイキスト判定が全部ここから出る。

## 3. 「どうすごいのか」の主張の型

**「モデルが凄い」ではなく「答え合わせが凄い」**。検証の4点セットを並べる:

1. インピーダンス: 様式5公表値と比1.22で整合(404線・弦距離下限に対し自然な迂回率)
2. 潮流: 観測潮流実績とSpearman 0.41(west)
3. 静的: 全4島AC収束・短絡容量が物理帯(66kV≈1-2GVA)
4. **動的: 実測で知られる西日本長軸振動(~0.4Hz)の周波数と地理形状を再現** ← 頂点

ヘッドライン例:
> 公開データのみから構築した全国送電網モデルが、西日本長軸振動(約0.4Hz・九州⇔中部関西の逆位相)を再現した

位置づけ: SciGRID・PyPSA-Eur・GridKit等の既存オープンモデルは静的トポロジ止まり。
**動的検証(文献周波数との一致)まで到達した公開モデルは例がない**。

## 4. 相手別の見せ方

- **学会/論文**: 検証の多重性(4点セット)+EGGC等の方法論(各層に独立の公表データで検算がある構造)
- **電力実務者**: 「内部資料でしか存在しなかった地図の、公開データによる民主化」
- **講義/一般**: 振り子とバネの比喩+**時間応答アニメ**(擾乱を入れると九州と関西が実際に
  シーソーする動画 — `swing_solver.run_transient`で作れる・未実施の最強デモ候補)

## 5. 注意書き(誠実性・必ず添える)

- 動的定数(H, xd″)は型式別典型値であり個別実測ではない(G表に明示列あり)
- 長軸振動は「帯と形の再現」であり、減衰率の定量予測には制御系(AVR/PSS/ガバナ)モデルが要る
- 介入台帳(MODEL_INTERVENTIONS #1〜#30)が全仮定の目録 — 「滑らかさは検証の証拠ではない」
