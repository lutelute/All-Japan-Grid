## 何を足したか

前の試作(`make_restoration_ops.py`)は送変電の作業班だけで、東京向けの応援が 5.4 班(約 43 人)と桁が小さかった。本版は配電の層を足す。

1. **電柱の折損**
   - 揺れ: 震度別の折損率(内閣府 首都直下 手法 資料3・岡山県 手法編 表4.3.2)
   - **建物全壊の巻き込み(本版で追加)**: 電柱折損率 = 0.17155 × 木造建物全壊率(同 資料3 PDF p.19「阪神淡路の実態による」)
     - 木造全壊率 = Σ 建築年次の構成 × Φ((I − μ)/σ)。I は母線の計測震度
     - 建築年次の構成は令和5年住宅・土地統計調査 第6-3表の市区町村別 木造住宅(e-Stat)。母線を N03 の市区町村に空間結合。表に無い小さな町村は「県 − 表にある市町村」の残り、境界が無い県は県全体
     - 曲線は 2005 年首都直下手法の「推計震度 6.4 のとき 71% / 50% / 11%」(旧 / 中 / 新築年、正規分布)を通るように置く
   - 津波: 浸水域 16.3%(内閣府 2025 概要・東北電力の実績)
2. **人**: 350 事業所(各社が公表する事業所 456 か所から本社・本店を除き、同じ会社の最寄りの事業所に母線を割り当てた。国土地理院の住所検索で座標化)、32,799 人(100 万口あたり 390 人 = 熊本地震・台風15号・台風21号・台風24号・2022 福島県沖地震の自社と協力会社の人数 / 契約口数の中央値)。震度・浸水で欠け、1 日で揃う
   - 電柱の本数は会社ごとの「配電設備 支持物数 / 契約口数」(有価証券報告書 FY2025)。東京・関西 0.19 本から東北 0.40 本まで
3. **社内の融通**: 1 日目から、残作業が自所 7 日分の 3 割未満の営業所が人員の半数を重い営業所へ
4. **他社応援**: 自社の被害度 r < 0.25 の会社だけが送る(災害時連携計画のプッシュ型応援の前提条件)。r ≥ 0.5 の会社が受ける。本店から陸路、北海道は海路で 1 日足す

- 建物全壊を入れると、配電の停電は 1 日後に 1.7 倍になる。曲線の幅を振っても 134〜200 万軒に収まる
- 応援の人数より、社内の融通と浸水域の着手時期(10 日・仮定)が効く
- 被害が増えると応援は**減る**。送り手は自社の被害度に応じて送る人数を減らし、σ = 0.6 では関西も受け手に回る。送り手の規則は計画の前提条件の読みで、南海トラフ級の実際の動員計画ではない

## 修正(2026-09-14 夜): 停電中の需要家の合計で復旧対象外を二重に数えていた

- 浸水ランク 3 以上の母線の需要家は津波で全壊相当として復旧対象外にしている。合計の式が、その需要家を「送電側の停電確率」の分だけ 2 回数えていた(`customers_out`)。
- 合計 =(復旧対象の需要家のうち送電側で停電)+(送電側では停電していないが配電で停電)+ 復旧対象外、に直した。内訳の和が合計になる。
- 7 日後の合計は 715 万軒 → 523 万軒。これより前のコミット(82ad7e6〜68f1cfc)の GIF・デッキ・本 README の合計は過大。感度表の「配電の停電」は送電側を問わない数え方で、値は変わらない。

## 桁の検算(内閣府 2025)

モデルが暗に置く木造全壊は、需要家数 × 木造の比率 × 木造全壊率の合計で約 108 万戸(東海 約 60 万・四国 約 16 万・近畿 約 13 万)。

内閣府「南海トラフ巨大地震 最大クラス地震における被害想定について【定量的な被害量】」(令和7年3月)PDF p.17 総括表の揺れによる全壊は次のとおり。

| 地震動ケース | 揺れによる全壊 |
|---|---|
| 基本 | 約 610,000 棟 |
| 陸側 | 約 1,279,000 棟 |

本解析の値は両者のあいだで、桁は合う。ただし戸と棟、需要家数と住宅数、J-SHIS の地震動と内閣府のケースが違うので、較正ではなく桁の確認にとどまる。

## 限界と未解決(負の結果を含む)

- **全壊率曲線の幅 σ は仮定**。内閣府(2005・2012・2025)の曲線の平均と標準偏差は本文に無く図だけ(補助 DB の missing D4)。県の手法資料での数値表を探索中
- 2005 年の曲線は阪神淡路の実態に基づく。2012 年以降の曲線との比較は一次資料で未確認
- 事業所の網羅性は会社で違う。北陸電力送配電は支社 4 か所とネットワークサービスセンターだけで、営業所相当の一覧は見つかっていない。事業所の名称は住所の直前の行から機械抽出しており、誤対応の可能性がある
- 人員は会社の人数を需要家数の比で事業所に配っている。事業所ごとの実人数は公表されていない
- 電柱の本数は会社全体の平均で、都市と山間の差は入れていない
- 住宅(戸)の建築年次の構成を建物(棟)の構成の代わりに使っている
- 地震火災・液状化・急傾斜地による電柱の被害は入れていない
- 7 日後の停電 523 万軒のうち、送電側(浸水した変電所と上流の孤立)が 256 万軒、津波で全壊相当(復旧対象外)が 219 万軒。内閣府 2025 より 4 日以降が 1 桁多い既知の問題で、人員モデルでは直らない
