# ajg-dist の配電の需要で県内の配り方を決める(介入#65・既定 OFF・2026-11-17)

## 何をしたか

AJG は県の需要を、点の数 × 電圧の重みで一様に配る。北海道は全域が 1 県なので、田舎の長い線に需要が載りすぎ、
北の宗谷・名寄の電圧が下がっていた(`hokkaido_north_voltage_2026-11-15.md`)。ajg-dist(配電の推定の網)は、
国勢調査の世帯と建物の面積から、配電用変電所(起点)ごとの需要を下から積んでいる(`Store.load_set`)。

先生「dist と連携できそう?」(11-16)→「いいよ、進めて」(11-17)。dist の需要の**割合だけ**で県内の配り方を決める
切り替えを入れた。**既定は OFF**(下の「東と西」)。

- `src/powerflow/dist_load.py`: dist の置き場から load_set を読み(`python -m ajg_dist load-set`)、起点の座標(catalog.csv)で
  AJG の母線に当てる。起点の需要を、半径 R km(既定 20)の中の 77 kV 以下の需要の点へ、電圧の重み × ガウスの重みでならして配る
- `allocate_loads(dist_share={"radius_km": R})`: 県(またはzone)の中の配り方をこの重みにする。県・zone の需要の合計は今のまま
  (地域のピーク × 負荷率 × 県別の実需要の割合)。dist の起点が 1 つも届かない県は今の電圧の重み
- 使わない起点: ほかの島の起点(dist の地域が網の区域に無い)・半径の中に需要の点が無い起点・観測の地点需要(#30)の母線から 0.5 km の中の起点(観測と二重に数えない)
- 切り替え: `run_full_powerflow_from_db.py --dist-load-share`(または環境変数 `AJG_DIST_LOAD_SHARE=1`)、半径は `--dist-radius-km`。
  置き場は `AJG_DIST_ROOT`(既定はこのリポジトリの隣の ajg-dist)・`AJG_DIST_STORE`(既定は `<root>/data/std`)
- 切っているときは要約(`summary.json`)も網も前と同じ(北海道・沖縄で、違いは解いた秒数だけなのを確かめた)

## 突き合わせ(名前でなく位置で)

dist の load_set には AJG の母線の名前(`agj_bus`、正典の点の id)が付いているが、正典を作り直すと id が変わる。
11-16 に確かめると、母線の付いた 2,593 行のうち 1,939 行は今の正典に同じ id があり、すべて 500 m 以内の正しい場所だった。
残りの 654 行は、11-09 の #58〜#61 と 11-15 の #64 の作り直しで id が変わっていた。そこで起点の座標で当てる。
北海道では、起点からいちばん近い母線まで中央値 40 m・9 割が 170 m の中。dist には母線の付け直しと座標の列を指示の箱で頼んだ。

### 北海道と沖縄は良くなる

- 北海道: 北緯 44.5 度より北の需要が 220 → 105 MW(人口の割合で見積もった約 110 MW と合う)。石狩の 22 kV の鎖は 8.0 → 3.6 MW
- 代わりに、需要の集まる都市の線が重くなる: 札幌の南九条大通地中線 195%・南九条円山地中線 130%・新琴似線 124%、那覇の周り(友寄〜南風原 333%・伊佐〜牧港 320%)

### 東と西は悪くなる — 既定 OFF の理由

- 東: 最低電圧 0.854 → 0.651、損失 +298 MW、100% 超の線 +96 本。重い線は 大郷町〜城内一 929%・板橋線 877%
- 西: 損失 +250 MW、100% 超の線 +87 本(志岐 681%・大畑町〜八草 498%・南河内喜志線 397%)
- dist の需要は都市に集まる(住宅と建物の面積から積むので、実態に近いはず)。ところが AJG の都市の網(地中の 66 kV・22 kV、
  都市の配電用変電所)は OSM に少なく、集まった需要を受けきれない。人口の 1 km メッシュで傾ける介入#40(pop_tilt、既定 OFF)が
  東西で解けなくなったのと同じ形
- dist 自身も、標準の最終規模 60 MVA を超える起点を 562 か所(全国の負荷の 44.8%)と記録している。都市の変電所が一覧に足りない
  可能性があり、その分の需要が少ない起点に載る

## 既定にする前に要るもの

1. **都市の網**: 札幌・東京・大阪・那覇の地中の 66 kV・22 kV と配電用変電所(dist の「都市の変電所が一覧に足りない」とも同じ根)
2. dist の起点の母線の付け直し(今の正典の id)と、起点の重さ(over_final_scale)の確かめ — 指示の箱で頼んだ(20261117-102044-5242)
3. 島ごとに入れる案: 北海道と沖縄だけ ON にすると良くなるが、島によって配り方の決まりが違うのは整合しない。都市の網を足してから 4 島で決める

## 量は使わない

dist の需要の合計は地域のピーク需要の 0.72 倍(全国)。北海道は 1.28 倍で、住宅以外の分が大きい理由は dist でも未解明。
1 戸のピーク 1.2 kW と大きい建物の 30 W/m² は dist の仮の値。AJG は割合だけを使い、合計は今のまま。

## 再現

```
AJG_DIST_ROOT=<ajg-dist の場所> PYTHONPATH=. python scripts/run_full_powerflow_from_db.py --islands hokkaido --dist-load-share \
  --output-dir /tmp/pf_dist --max-ac-buses 20000
```
