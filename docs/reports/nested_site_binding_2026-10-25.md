# 介入 #53 変電所の敷地が重なるときの線の結び先 2026-10-25

`docs/reports/canon_reproducibility_2026-10-24.md` の 5（多角形の選び方が OS で変わっていた）で残した問題です。オーナーは「任せる」（10-25）と回答しました。採否は一次資料との一致で決めました。

## 何が問題だったか

- 線の点を変電所に結ぶとき、点を覆う多角形が複数あることがあります。外側の大きい敷地の中に、内側の変電所の柵があるような所です。
- #106 では、順に依らない決め方として「外側（面積の大きいほう）」を選びました。ほとんどの所で、それまでの木の順の結果と同じになるからです。
- ところが外側を選ぶと、明らかに誤る所がありました。

## 決め方（#53）

点を覆う多角形どうし（距離 0 で並ぶとき）では、次の順に小さいものを選びます（`src/powerflow/snapped_topology._nested_site_rank` と `_poly_pick`）。

1. 施設かどうか: 名前が研究所・電力所・事業所・支社・営業所・制御所・給電所で終わり、変電所・開閉所・変換所・連系所・発電所などで終わらないもの
2. OSM の実名が無いかどうか: 名前が無いか、住所から作った名前（`_name_source=geocoded`）
3. 面積の大きいほう（外側）
4. 多角形の番号の小さいほう

距離が違う候補どうしでは、今までどおり近いほうを選びます。

- 結び付け先が変わる点は 162 です（`nested_site_binding_2026-10-25/changed_points.json`）。北江別 118・江別 36・西掛川 3・田端 2・メディポリス 2・会津若松 1。網干と南福光は変わりません。
- 図: `nested_site_binding_2026-10-25/before_after.png`（赤 = 外側の施設・住所名の多角形、青 = 変電所、点 = 線の点の結び先）

### 却下した案

- **施設を距離より先に見る**（施設の多角形が点を覆っていても、届く範囲に変電所の類があればそちらへ）
  - 総合研究所の敷地の中で柵の外にある点も北江別・江別へ移せます。しかし「電源開発株式会社北地域制御所」の 187 kV の線まで、600 m 先の北七飯変電所へ引っ張りました。
  - この多角形は OSM で `substation=converter`・187 kV です。名前は制御所でも、実体は北本連系の函館変換所です。名前の語だけでは施設と言えないので、却下しました。
- **語に「センター」「工場」を入れる**
  - 「別子配電センター」（住友共同電力の配電の設備）が施設扱いになったので外しました。
- **OSM のタグで施設を見分ける**
  - 総合研究所も電力所も `substation=transmission`・電圧付きで登録されていて、見分けられませんでした。

## 残っていること（正直に）

- **総合研究所のノードには、まだ線が 8 本（187 kV に 3・66 kV に 5）つながっています。**
  - 動いた 162 点の多くは、変電所の柵の中の点でした。線の端は、研究所の敷地の中で、変電所の柵の外で終わっています。研究所の多角形はそれを覆うただ 1 つの多角形なので、#53 は効きません。
  - 研究所を電気の結節点として扱わないには、この多角形を根拠付きで結び先から外す直し（OSM のデータの誤りとして台帳に載せる）が要ります。掛川電力所（3+3 本）も同じです。次の判断の候補です。
- 正典の手順での再現（clone からのバイト一致）は、CI の `reproduce-canon` で確かめます。
