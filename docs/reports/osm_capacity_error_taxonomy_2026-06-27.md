# OSM 発電所容量の系統的誤り — 出典付き訂正からの経験的知見 / Systematic capacity errors in OpenStreetMap power plants

作成 2026-06-27 / モデル claude-opus-4-8。All-Japan-Grid の「出典必須・捏造禁止」容量収集キャンペーン（`data/generator_capacity_sources.jsonl`, 160件）の実データを、収集時の OSM 値（`docs/reports/capacity_worklist_2026-06-20.json`）と突合して分類した、再現可能な経験的知見。**これは方法論であると同時に、それ自体が公表可能な発見**（OSM の発電所容量がどの程度・どう間違うかの定量化）。

---

## 0. 要旨 / Executive summary

大規模発電所 156件（出典160件のうち OSM値と突合できたもの）について、**OSM の `capacity_mw` は約60%が一次出典と一致し、約40%が系統的に誤っていた**。誤りはランダムでなく、**5つの識別可能なメカニズム**に分類できる。最大は「廃止/中止/未建設の発電所を運転中容量として保持（17%）」と「多号機プラントの号機半数え（過小15%）」。最悪は ~700倍（蘇我ソーラー 1440→1.99 MW）。容量に依存する解析（dispatch・潮流・容量市場）を OSM 生値で行うと、**4割の大規模電源で実容量と乖離**する。

## 1. 方法論 / Method — no-fabrication provenance

各容量値は次のゲートを通った値のみ採用（`scripts/capacity_provenance.py`）:
- `source_url`（`^https?://` の実URL、空・非URLは機械 REJECT）
- `quote`（容量を述べる**原文抜粋**、空は REJECT）＝人/機械が出典を開いて照合可能
- `source_type ∈ {official, gov, ir, wikipedia, news, other}` / `confidence ∈ {high, medium, low}` / `retrieved_at`(YYYY-MM-DD) / `collected_by`
- 検証: `capacity_provenance.py verify` = **160 ok / 0 bad** を実走再現

収集フロー: `screen_capacity_gaps.py`(燃料順 worklist) → 並列エージェントが WebSearch/WebFetch で一次出典照合 → `validate_record` で形式強制 → 追記。**廃止/建設中は現況容量（0含む）を正直に記録、出典不確かは SKIP（発明しない）**。

## 2. 誤りの分類 / Error taxonomy（156件突合, OSM値 vs 一次出典）

| 区分 / Category | 件数 | 割合 | 機序 |
|---|--:|--:|---|
| 一致 (±10%) | 93 | **60%** | OSM が正しい（主に大規模火力で正確） |
| **廃止/中止/未建設 → 0** | 27 | **17%** | 退役・計画中止・着工中の電源を運転中容量として保持 |
| **OSM 過小（<2/3, 号機半数え等）** | 23 | **15%** | 多号機プラントで一部号機のみ計上（しばしば 1/N） |
| OSM 過大（>1.5x, 廃炉込み等） | 9 | 6% | 退役済み号機を総出力に含む |
| **粗誤差（>5x or <1/5）** | 4 | 3% | プラント取り違え・幻値・スタブ値 |
| **誤り合計** | **63** | **40%** | |

## 3. メカニズム別の代表例 / Mechanisms with evidence

1. **廃止/中止/未建設を運転中として保持（17%）** — 和歌山火力(計画中止, OSM 2056→0)、南港火力(更新工事中, 1800→0)、秋田火力(全廃2024, 1633→0)、大間原子力(着工中・未運開, 1383→0)、福島第一原子力(全炉廃止措置, 1380→0)、Higashi Niigata Minato(港号機2022廃止, 1700→0)。**OSM は "かつて存在した" 容量を残しがち**。
2. **多号機の号機半数え（過小15%）** — 玄海原子力(1180→2360, ちょうど2倍=2号機中1号機のみ)、三隅/松浦/新地火力(1000→2000, ×2基)、広野火力(1000→4400, ×4.4)、上越火力(1440→2380)。**OSM は1号機分のみをプラント値にしがち**。
3. **退役号機込みの過大（6%）** — 大飯発電所(4494→2360, 1・2号機 廃炉)、知多火力(3966→1700)、新小倉/御坊火力(1800→1200, 号機廃止)、伊方原子力(1456→890, 3号機のみ運転)。
4. **未建設号機込みの過大（水力に多い）** — 神流川水力(2820→940, **6基計画中2基のみ運転**)、葛野川(1600→1200, 3号機未運開)。**OSM は設計計画値を保持しがち**。
5. **プラント取り違え・幻値・スタブ（粗誤差3%）** — 蘇我ソーラー(1440→**1.99**, ×0.0014=中止した蘇我火力107万kWと混同)、柏崎刈羽原子力(1356→**8212**, ×6=7基中1基のみ計上)、JX Sendai(980→90, ×0.09=隣接 新仙台火力と混同)、高浜発電所(25→3392, ×136=スタブ値)。

## 4. 含意 / Implications

- **OSM の発電所容量は大規模電源で約60%信頼でき、40%が系統的に誤る**。誤りの向きは予測可能（廃止→過大に残る／多号機→過小に半数え／計画→過大に先取り）。
- **容量依存の解析（merit-order dispatch・潮流・容量市場・脱炭素シナリオ）を OSM 生値で行うのは危険**。少なくとも大規模電源は一次出典で訂正すべき。本キャンペーンの 63件の訂正がその規模感を示す。
- **AGJ 自身への含意（正直な限界, formal_review H2）**: これら訂正は現状 `capacity_mw_sourced`（地図表示）に留まり、潮流ビルダは `capacity_mw`（OSM生値）を読む。したがって**蘇我=1440MW・大間 等の"幻発電所"は AGJ の検証潮流 dispatch にまだ残存**する。訂正を `capacity_mw` へ伝播させるか「表示専用」を明示するのが次の一手（DATA_DICTIONARY §3.4 で開示済）。
- **スコープ**: 本分析は燃料順 worklist 上位（大規模電源）に限る。小規模（<500MW）・再エネ点では OSM の網羅性・正確性はさらに低い可能性が高い（未計測）。

## 5. 再利用 / Reusability

検証器（`scripts/capacity_provenance.py`、stdlib のみ、`validate_record`/`verify`/`selftest`）と正本 JSONL は本リポジトリにあり、他地域・他属性（電圧・事業者・レーティング）へ一般化可能。**「URL＋原文引用が無い値は機械 REJECT」**という規律は、LLM エージェントによるデータ収集の捏造を構造的に封じる再利用可能パターンである。
