# OSM利用の課題例題: 関西と北陸 — Fable 5 記録

- **日付**: 2026-06-10 / **モデル**: Claude Fable 5 / **発端**: ユーザー指摘
  「関西と北陸の問題はOSMを利用する上での課題として、いい例題になると思う」
- **位置づけ**: OSMから電力系統モデルを作る研究・論文・講義で使える、実測数値つきの教材的事例。
  数値の出典は `docs/reports/topology_*_2026-06-10.json`（①の検証フレームワークで計測）。

## 例題1: 関西 — 「地図の見かけ」と「電気モデルとしての使用可能性」の乖離

OSM上で関西の送電網は密に描かれている（3,994線フィーチャ、名前タグ100%）。しかし:

| 指標 | 実測 | 含意 |
|---|---|---|
| 電圧タグ欠落 | 全線の**31%** | 電気モデル化の最重要属性が1/3欠落 |
| 合成線率（改善前） | **14.4%**（全国最悪） | 幾何ギャップを人工橋で埋めないと連結しない |
| 公式線リストとの名前一致 | **40%**（厳密17.9%） | 500kV基幹34線中**20線が名前で発見不可**（東播線・丹波線・能勢線等）。OSMの命名流儀（変電所名ペア式等）が公式名と乖離 |
| `circuits`タグと公式回線数の一致 | **56%** | タグはあっても半分は公式値と不一致 |
| フルモデルAC | **非収束** | 下位網(66-132kV)の539変圧器・電圧比最大20が作る悪条件Ybus（docs/WEST_AC_ANALYSIS.md で実験確定） |

**教訓**: (1) OSMの品質は地域コミュニティ依存で**東西非対称**（east電圧タグ欠落4-8% vs west 25-33%）。
(2) 「描いてある」ことと「電気的に解ける」ことは別物 — 検証なしにOSM系統モデルを潮流に使うのは危険。
(3) 公式開示（関西送配電CSV）との突合で初めて欠落が**定量化**できた — 外部正解の確保が先決。

**対処の実例**: 多電圧変電所化+証拠ベース接続で合成線率14.4→8.9%、basebone縮約でAC収束
（vm 0.92、Q制限拘束下）。ただし下位網のAC級モデル化は権威パラメータ（OCCTO等）なしには不可能のまま。

## 例題2: 北陸 — 属性欠落が連結性を壊す（幾何ではなく）

北陸はbackboneモデル(≥154kV)でも合成線率**11.1%**と唯一の外れ値（他地域≤3.6%）。診断:

| 指標 | 実測 |
|---|---|
| 電圧クラス分布（枝） | 154kV: **314**（主幹）/ 275kV: 115 / 500kV: 39 / 66-77kV: 258 |
| 電圧タグ欠落 | **220枝（23%）** |
| ビルダー段階の成分数 | 42（カバー85%） |

機序: 北陸の主幹は154kV。**154kV回廊の中間セグメントが無タグ**だと、その枝は電圧不明として
backbone断面（≥154kV）に入れず、回廊が分断 → 合成橋で補うしかない。つまり
**幾何データは存在するのに、属性（voltage）の欠落だけで連結性が壊れる**。

**教訓**: (1) グラフの連結性は「線があるか」ではなく「属性が揃っているか」で決まる場面がある。
(2) 欠落属性の推論（@uバスの電圧推論）には限界があり、回廊の電圧クラス伝播のような
**経路ベースの推論**が次の改善候補。(3) OSM貢献としては「北陸の154kV線に voltage タグを付ける」
だけで model が大きく改善する — 貢献先の優先順位付けに検証KPIが使える。

**仮説の実測検証（2026-06-10追補・回廊電圧伝播の実装後）**: 一意な隣接クラスからの反復伝播で
北陸の電圧不明枝は23.2%→**10.8%**（119枝を型付け）、全国でも軒並み半減〜1/3
（中部25.8→8.2%・関西25.0→8.2%）。しかし**北陸のbackbone合成線率は11.1→10.2%と部分改善のみ**。
つまり「属性欠落が分断の主因」仮説は**一部のみ正しい** — 残差は (a)複数クラスが交わる曖昧頂点
（伝播は安全側で棄権）と (b)真の幾何ギャップ。属性修復だけでは外れ値は解消しない、という
ところまで含めて例題になる。副次的発見: 伝播は沖縄北部の66kVスパーを正しく型付けし、
従来は暗黙の高クラス扱いで**隠れていた電圧降下（vm 0.65）を顕在化**させた — 推論の改善が
見かけの指標を悪化させる（=より正直になる）例。

## 対照: 東京 — データが良い地域の「残る課題」は接続正確性

東電の地点別潮流実績CSV（変電所×線路名の列構成=公式接続ペア286組）との照合（2026-06-10初計測）:

| 指標 | 実測 |
|---|---|
| 変電所recall | **86.4%** |
| 線路名recall | 50.8%（厳密）/ **82.1%**（包含） |
| **接続ペアrecall** | **45.8%**（131/286）。「線はモデルに在るが公式の変電所に接続していない」**103件** |

データが揃っている東京でも、**個々の線がどの変電所に終端するか**のレベルでは半分しか合っていない
— スナップ・ジャンクション推論の限界が103件の固有名詞つき作業リストとして可視化された。
（次の改善はこのリストを直接潰せる: 例「京浜(変)-東京南線」が未接続なら当該端点の状況を個別に見る）

## 追補: 東京103未接続ペアの故障モード分類（2026-06-10）

`docs/reports/tepco_unattached_failure_modes_2026-06-10.json`（92件を3分類）:

| モード | 件数 | 内容と対処 |
|---|---|---|
| **B: 端点0.7〜2.5kmで別変電所へスナップ** | **23** | スナップが距離だけで決まり名前を見ない。**名前一致を優先するスナップ**で直せる明確なターゲット |
| A: 公式変電所がモデルに不在 | 20 | ただし信濃川・南いわき等は**地域スライス境界の外**（隣接地域に実在）の可能性大。真のOSM欠落との切り分けが先 |
| D: 同名線の幾何が5〜22km遠い | 49 | 「京浜線 9km」等は**鉄道き電線との名前衝突**の疑い。po wer=line以外の用途識別 or operator タグでの除外が必要 |

教訓の追加: **名前ベース照合には鉄道き電線という偽陽性源**がある（OSMでは鉄道事業者の送電線も
power=lineで同名規則）。operator タグ（東京電力PG vs JR東日本）でのフィルタが照合精度の次の一手。

## 追補2: 東京 — 都心154kV地中ケーブル網のOSM不在（2026-06-11・台帳㉝）

東電の154kV開示CSV（6ファイル・184回廊）を解剖すると、119本は幹線（275/500kV）の
重複掲載で、**純粋な154kV回廊は65本**。うち20本（約3割）がOSMにまったく存在しない:
北渋谷線・和田堀線・戸越線・常盤橋線・墨東線・南池上線など、**都心部の地中ケーブル網**に
集中する。

教訓: OSMの送電網カバレッジは「架空線はほぼ完備・**地中ケーブルは系統的に欠落**」という
構造的偏りを持つ（衛星画像・現地視認でマッピングできないため）。これは地方の属性欠落
（例題2北陸）とは別種の、**手法では回収不可能な欠落**であり、検証指標の到達上限を規定する
（154kV層の流れ照合は n≈45 が現データの天井）。開示データ側から線名つき欠落リストを
生成できたこと自体が検証フレームワークの成果で、OSMコミュニティへの具体的編集ターゲット
として還元できる。

## 研究・教育上の使い方

- **論文の motivation**: 「OSMベース系統モデルの品質は地域非対称で、属性欠落が連結性を支配する」
  の実証データ（papers/ の IEEJ 原稿に直結）
- **講義の例題**: 同じ手法・同じ国でも入力品質で結果が桁で変わる例。検証フレームワーク
  （`ajgrid validate --topology` / `external_match` / `external_tepco`）でライブ再現可能
- **OSMコミュニティへの還元**: missing リスト（関西141線・北陸の無タグ154kV・東京の未接続103ペア）
  は具体的な編集ターゲット
