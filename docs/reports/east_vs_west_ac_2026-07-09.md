# east と west を分けて診断する — 同じ無効電力律速、違うのは断片化の重さ（2026-07-09）

## 0. なぜこの文書か

全島24h検証（`allisland_24h_reactive_2026-07-09.md`）の表は「east=AC / west=DC」と
並ぶため、**ACとDCという別種の問いを混ぜていて解釈しづらい**という指摘を受けた。
実際、west の「24/24 DC」は DC潮流が無効電力も電圧も無視するためほぼ必ず成立する値で、
モデル品質を何も語っていない。そこで east にやった網側診断（①DC角度は健全か
②無効補償でACが立つか）を **west にも同一手順で当てて**、両島を横並びで比較した。

## 1. 結論

**east と west は「AC島／DC島」という別種ではなく、同じ無効電力律速の同種問題。**
違いは west の断片化がはるかに重く（成分数5倍）、AC収束が限界的なこと。

| 観点 | east | west |
|---|---|---|
| バス数 | 6,222 | 10,193 |
| 低圧網比率（≤110kV線） | 66kV 78% | ≤110kV 68% |
| **DC角度の健全性** | 健全（45°超0本） | **健全（45°超0本）** |
| 角度prune ladder | 効かない（thr45で0本） | **効かない（同じ）** |
| **AC非収束の真因** | 無効電力／電圧崩壊 | **無効電力／電圧崩壊（同じ）** |
| 負荷無効需要 | 18.9 GVar | 22.0 GVar |
| **成分数（無刈り時）** | 533 | **2,531（≈5倍）** |
| 主成分の負荷占有 | 89% | **69%** |
| **必要補償率でAC成立** | factor **0.3** で98%給電 | factor **0.9** でようやく |
| **収束の頑健性** | 両順序で収束（頑健） | **特定順序のみ・CLI順序ではno AC（限界的）** |
| 補償ありの損失 | 11%（実潮流あり） | 3.6%（断片で長距離潮流が乏しい） |

## 2. 診断の内容

east と同一の2プローブを west に適用（`docs/reports/probes/east_reactive_2026-07-09/`
の `diag_island.py`（島引数化版）と `probe_reactive.py`）。

### 2.1 DC角度は west も健全

west の DC角度差は全階級で小さい（66kV max 45.0°・他は<27°・45°超0本）。east と同じく
**角度ベースの prune ladder は無効**（thr45で0本、thr30で2本、thr20でも9本刈るのみで
AC非収束）。→ west も angle でなく無効電力の問題。

### 2.2 無効補償スイープ — west は east より深刻

| island | factor 0.0 | 0.3 | 0.6 | 0.9 |
|---|---|---|---|---|
| east | dc_fallback | **AC 98.2%** | AC 98.2% | AC 98.2% |
| west | dc_fallback | dc_fallback | dc_fallback | **AC 99.8%** |

east は30%補償で立つが、**west は90%補償でようやく**立つ。west は同じ無効電力律速でも
はるかに深刻（負荷無効22GVarに対し補償20GVar＝ほぼ全量を局所供給して初めて解ける）。

### 2.3 west の AC は限界的（順序依存）

west の factor=0.9 AC は**シャント整定の順序に依存**する:
- 補償スイープ（注入で負荷スケール後にシャント付与）→ **AC 99.8%成立**
- 分解プローブ／**実CLI**（シャント付与後に注入）→ **no AC**

east は**両順序で収束**（分解プローブ=CLI順序でも thr30 でAC・主成分に89%負荷）。
west だけが順序に敏感で、**運用経路（CLI順序）では0.9でもACに届かない**。
→ west の AC は数値的に崖っぷちで、わずかな整定差で消える。

### 2.4 west の「低損失・クリーン電圧」は断片化の副産物

west の補償ありAC（成立時）は損失3.6%・vm[0.68,1.02]と east（11%・vm上限1.70）より
一見「良い」。しかしこれは west が2,531成分に断片化し**主成分が全体の69%しかない**ため、
多数の小片が各々ローカルslackで釣り合い、長距離潮流が乏しいことの副産物。
「west の方が良いモデル」ではなく「west の方が細切れ」を意味する。

## 3. 判断

- **「west = DC が既定」は妥当**とデータで裏づけられた。west は east と同じ無効電力律速
  だが、断片化（成分数5倍・主成分69%）が重く AC収束が限界的で、運用経路では立たない。
  west の AC実証は backbone（≥154kV集約）が担うのが正しい。
- east の網側課題（局所電圧外れ値41バス）と west の網側課題（重度断片化）は**別の課題**。
  east=「概ね連結した網の局所弱点」、west=「網が細切れ」。前者は無効配分・並列回線の精緻化、
  後者は**接続の回復（欠損連系線・変電所ハブ化）**が効くはず。両者を同じ表で語るべきでない。
- **west AC を無理に立てにいかない**（順序を変えれば数値的には立つが、69%しか連結して
  いない解を「解けた」とするのは見せかけAC解の系譜。ハマり⑩の精神）。west の本丸は
  断片化の解消（トポロジ）であり、無効補償や整定チューニングではない。

## 4. 次アクション（東西で分ける）

- **east**: 局所電圧外れ値41バスの網側精緻化（並列回線・変圧器容量・無効配分）。
- **west**: 断片化2,531成分の主因調査（OSM欠損連系線・変電所ハブ化＝GridStitch系の課題）。
  接続を回復してから改めて無効補償を評価する。
- 補償のシャント整定順序（注入後に合わせる方が物理的に正しい）は将来の設計事項として記録。
  ただし west をそれで収束させても本質（断片化）は残るので、優先は接続回復。
