## 1. 方法(東北NWで実証したフローの全国展開)

1. 各社の系統情報公表ページから「主要変電所の整備計画」「送変電設備の投資・廃止計画」PDFを特定
   (TEPCOは WebFetch が 403 → **curl + ブラウザUA で取得**が必要だった)
2. PDF をローカル保存 → Read で表を読取(並列サブエージェント8体で8社同時)
3. 中間JSON(社別)に「表の記載そのまま」を保存 → 統一コンバータでレコード化
4. **三重確認**: (a)バリデータ機械拒否(URL実在形式・quote必須・数値検証) (b)収集エージェントの
   原文転記 (c)独立 spot check — 中部・東栄 800→3,000MVA と関西・信貴 750MVA×1(2029-6) を
   原文PDFと突合し完全一致

## 3. レコード化規則(誠実さ最優先)

- **status=planned 一律**: 整備計画=将来断面。`apply_transformer_provenance` は existing のみ
  適用するため現況の構造DB/Ybusには影響しない(再生成で summary 不変を確認済み)
- **sn_mva と sn_total_mva の峻別**: 台数が明示された行(東京/北海道/関西/中国/四国の様式)のみ
  sn_mva(1台あたり)。台数列が無い様式(中部=合計MVA明記・九州)は sn_total_mva。
  沖縄の「2B」等バンク特定行は単一バンクの容量なので sn_mva
- **hv_kv/lv_kv を併記**(単純2値の電圧比のみ・89/80件): 将来 existing 昇格時に階級ペアで
  正しい TransformerSpec へ適用するための第一級データ。三巻線(220/110/60等)は hv のみ
- **増容量「X→Y」は Y を採用**し note に増容量の旨と旧値を保持
- **転載禁止資料**(東京/関西/北陸ほか)のため quote は該当行の最小抜粋のみ
- 中国・九州の原表は万V/万kVA表記 → kV/MVA へ ×10 換算(note に明記)
