# 第7波: westフルAC後の残課題監査 (2026-08-30)

第6波(介入#38)でwestフル7,928バスAC成立後の残課題3件を並列調査した記録。

## 1. west 24時間AC率 — 19/24時刻でAC
`uc_to_pf_built --islands west --all-hours` (fy2023r2):
- **AC 19時刻 / dc_fallback 5時刻(t=10〜14の昼間帯)**・全24時刻収束・served 100%

  (低負荷側潮流での電圧上昇/Q収支が仮説)

## 2. 江田島66kV低電圧(vm 0.67) = (c)負荷過大配分が主因
- 給電経路はOSMに実在(呉→音戸→倉橋島→江田島の放射フィーダ、欠測ではない)
- 真因: allocate_loadsの県別×電圧階級一様配分で広島県66kVは一律34.47MW/バス。
  江田島市4バス=137.9MW vs 実勢ピーク≈30MW → **4〜5倍過大**
- 増幅要因: 実在の長距離放射(大柿線8.98km単回線に容量比170%)+既定100MVA変圧器
- 修正候補: 負荷配分の市区町村粒度化 / point_demandピン / 呉・宮原110/66の銘板調達

## 3. 大阪三国77kV低電圧(vm 0.73) = (b)上位接続欠測 + #37の仕様穴
- 真因は1段上: {味生154, 西三国154}の2バスクラスタに275/154変圧器が皆無。
  大阪77網から**逆潮で2段直列100MVA変圧器**経由の給電(157.5MW)
- #37が見逃す理由: クラスタ自kv負荷39.4MW < 100MW。**下流変圧器配下の負荷
  (77側118MW)を算入しない仕様穴**。backboneでは集約により検出→(仮)縫合で
  vm 0.941に健全化済 = 上位欠測が原因である実証
- 修正候補(推奨順): #37の負荷集計を「クラスタが唯一給電元の下流負荷」込みに変更
  (157.5MW≥100で閾値不変のまま検出。min_load=30引き下げは+33件/1.8GWの
  (仮)乱発で不採用)。並行して西三国154の実給電線の出典探索(豊崎154が3.5km先)

## 4. tokyo_sub×西region 41件監査 = disclosure v2「旧ID適用」事故
- 根本原因確定: `disclosure_connection_worklist_v2.json` の region_fixes(161件)に
  ノード再採番前の旧IDが重複収載され、旧IDを現在持つ**無関係ノード**のregionを
  書き換えた(巻き添え14件。例: 「小海町」fix が佃野町変電所(神奈川)に命中)
- 介入#38がビルド時に15件を是正することをシミュレーション確認済み
- **残留5件**(混在県=静岡・長野座標でガード維持: chubu_sub_446/555/661/697/914、
  全てmain=False)+未達2件(伊豆山→tokyo、勝間→chubu)。west島から計7辺欠落
  するが島の分断なし・影響は局所的(最重要=大桑村_4 154kV deg3)
- 修正候補: region_fixesを名前+座標(<300m)アサートで再適用し旧IDエントリをrevert、
  残留5+未達2は手動是正リスト、all.json再生成(現状#38はビルド時のみ)
