# 構想: 単相100VコンセントPMU網 — モデル検証の「第5層」(2026-08-17 オーナー発意)

「PMUを単相100Vに繋ぐとできること、その数で解析できること」— 発意はオーナー。
先例=米FNET/GridEye(壁コンセント周波数計測網・テネシー大)。日本の分散網は未開拓。

## 原理
周波数と低周波動揺(0.2〜1Hz)は系統全体で共有される量であり、配電末端の単相100Vでも観測できる。
単相の位相そのものは配電変圧器の結線(Δ-Y等)と局所負荷でずれるが、**周波数・動揺成分・
イベント伝播は系統共通** — FNETが十年以上の運用で実証済み。

## 台数×できる解析
| 台数 | 解析 |
|---|---|
| 1台 | 周波数イベント検出。df/dt→脱落電源の規模推定(慣性既知なら ΔP≈2H·S·df/dt/f) |
| 2台 | 長軸振動の位相差=モード直接観測(九州×関西で0.43Hzのシーソー)・地域間角差=潮流の代理 |
| 3台+ | 周波数波の到達時刻差→擾乱源の位置標定(三角測量) |
| 10台+ | モード形の実測地図→本モデルの振動地図(gen_swing_map)と直接突合 |

## AGJモデルとの閉ループ(ここが独自性)
- モデルの予言: west 0.434Hz・九州⇔中部関西逆位相 / east 0.592Hz — **測るべき周波数と場所が先にわかっている**
- 位置標定に必要な「周波数波の伝播速度」は慣性密度分布=本モデルのM分布から計算できる
- 実測が得られれば: 検証4層(様式5/潮流実績/物理帯/文献0.4Hz)の上に「自分の計測」=第5層

## ハードウェアの現実解
- GPS 1PPS(または PTP/NTP+補正)+ADC+Raspberry Pi級 — 数千円〜。商用品ならopenPMU等
- サンプリング: 50/60Hzの位相推定は数kHzで十分。周波数分解能はウィンドウ長次第(0.4Hz観測には10s窓で十分)
- 注意: コンセント極性・絶縁(変圧器またはZCT経由)・宅内ノイズ(インバータ家電)のフィルタ
