# 公表インピーダンスとの答え合わせを 3 つの視点で見る + 照合バグの修正 (2026-08-19)

オーナー依頼「(X公表)/(Xモデル) の中央値 = 1.22 を、解析的・地形的・Ybus 的に見たい」。
作図の過程で**照合の取りこぼし**が見つかり、直したので併せて記録する。

図: `figs/impedance_{scatter,map,ybus}.png` ／ 生成: `scripts/plot_impedance_validation.py`
（入力は `data/external/`＝.gitignore。`AGJ_DISCLOSURE_NORM` で場所を差し替えられる）

## 0. 定義

X_モデル = 線種の典型 x[Ω/km] × **弦距離** ÷ par（スライドと同じ）。
弦距離は実線長の下限なので **比 > 1 が自然**で、この比は実質「迂回率」を測っている。

## 1. 解析的 — 散布図

- **n=270・比の中央値 1.202**（四分位 1.02–1.35）。log-log で公表とモデルは同じ直線に乗る
- 84% 超が比 1 以上。1 を下回るのは都市部・地中が多い

## 2. 地形的 — 地図

乖離は**地域でまとまる**。四国 1.57 / 北陸 1.42 / 北海道 1.31 に対し、**東京は 0.96 と 1 を下回る**
（都市部・地中で迂回が小さい、と読める）。地図でも東京周辺が青、中国四国が赤に染まる。

## 3. Ybus 的 — 検証カバレッジ

**これが一番厳しい絵**。Ybus の非零 39,530 要素のうち、公表 X で検算できたのは **540 要素 = 1.37%**。
「比 1.20 で整合」は**行列の 1.4% での話**で、残り 98.6% は線種の標準値のまま。
色の散り方から、検証が地域的にも偏っていることが見える。

## 4. ★ 照合バグ: 九州の「1北九州」を匿名化として捨てていた

図を作る過程で、**九州の解決率が 0%**（121 本中 0 本）であることに気づいた。原因は:

```python
ANON_RX = re.compile(r"[□■○×]{2,}|^<\d+>|^\d+[^\d]")  # ← 先頭が数字なら匿名化とみなす
```

九州電力送配電の様式5は「**1北九州**」「**26山家**」のように**連番＋実名**で書かれている。
`^\d+[^\d]` がこれを匿名化と判定して、照合前に全部捨てていた。
実際には端点ラベル 46 種のうち **25 種は番号を剥がすだけで OSM の変電所名と一致**する。

### 修正

- `ANON_RX` から `^\d+[^\d]` を削除（真の匿名化 `□□□□` と `<12>` のみ残す）
- `with_seq_stripped()` を追加し、先頭連番を剥がした候補で照合する
- ついでに入出力を `AGJ_DISCLOSURE_NORM` / `AGJ_DISCLOSURE_OUT` で差し替え可能にした
  （`data/external/` は .gitignore なので、リポジトリ外のデータで回せるようにする）

### 効果（実測）

| 指標 | 修正前 | 修正後 |
|---|---:|---:|
| 両端解決 | 411 | 423 |
| **評価対象（弦>0.5km & X>0）** | **109** | **270** |
| **評価に入った事業者** | **6 社** | **10 社（全社）** |
| **Ybus カバレッジ** | **0.55%** | **1.37%** |
| 比の中央値 | 1.241 | **1.202** |

**東北が 0 → 74 本**、中部 0 → 30、沖縄 0 → 12、九州 0 → 4 と、
これまで丸ごと評価から外れていた事業者が入った。
**中央値は 1.24 → 1.20 とほとんど動かない** ＝ 母集団が 2.5 倍になっても結論は変わらない（頑健）。

## 5. まだ残っている問題

- **外れ値に誤マッチ**: 比 <0.5 または >2.5 が 28 本（10%）。
  例: chugoku 110kV で弦距離 167km（110kV でこの距離は不自然＝両端の対応付けが誤り）
- **未解決 746 端点の大半は `unknown`** ＝ モデル（OSM）側に該当変電所が無い。
  これは #38（OSM への逆貢献）の領域で、照合ロジックでは埋まらない
- **OCCTO から追加取得**（オーナー提案）: 系統情報サービスは登録制。
  ただし**追加取得より先に、手持ち 1,009 本の歩留まり**（現状 270/1,009 = 27%）を上げる方が効く

## 6. 次の一手

1. 他社の匿名化パターンも同様に解読できないか（沖縄 21% / 中国 27% が低い）
2. 誤マッチ検出: 弦距離と電圧階級の物理的整合（110kV で 167km は棄却）をチェックに入れる
3. `unknown` 端点を #38 の OSM 逆貢献リストに合流させる
4. OCCTO の系統情報サービス（登録制）で、様式5以外に設備諸元が取れるか調査
