# 公表インピーダンスとの答え合わせを 3 つの視点で見る + 照合バグの修正 (2026-08-19)

オーナー依頼「(X公表)/(Xモデル) の中央値 = 1.22 を、解析的・地形的・Ybus 的に見たい」。
作図の過程で**照合の取りこぼし**が見つかり、直したので併せて記録する。

図: `figs/impedance_{scatter,map,ybus}.png` ／ 生成: `scripts/plot_impedance_validation.py`
（入力は `data/external/`＝.gitignore。`AGJ_DISCLOSURE_NORM` で場所を差し替えられる）

## 0. 定義

X_モデル = 線種の典型 x[Ω/km] × **弦距離** ÷ par（スライドと同じ）。
弦距離は実線長の下限なので **比 > 1 が自然**で、この比は実質「迂回率」を測っている。

## 1. 解析的 — 散布図

- **n=249・比の中央値 1.228**（誤マッチ除去後の値。§4.5 を参照）。log-log で公表とモデルは同じ直線に乗る
- 84% 超が比 1 以上。1 を下回るのは都市部・地中が多い

## 2. 地形的 — 地図

乖離は**地域でまとまる**。四国 1.57 / 北陸 1.42 / 北海道 1.31 に対し、**東京は 0.96 と 1 を下回る**
（都市部・地中で迂回が小さい、と読める）。地図でも東京周辺が青、中国四国が赤に染まる。

## 3. Ybus 的 — 検証カバレッジ

**これが一番厳しい絵**。Ybus の非零 39,530 要素のうち、公表 X で検算できたのは **498 要素 = 1.26%**。
「比 1.23 で整合」は**行列の 1.3% での話**で、残り 98.6% は線種の標準値のまま。
色の散り方から、検証が地域的にも偏っていることが見える。

## 4. ★ 照合バグ: 九州の「1北九州」を匿名化として捨てていた

図を作る過程で、**九州の解決率が 0%**（121 本中 0 本）であることに気づいた。原因は:

```python
ANON_RX = re.compile(r"[□■○×]{2,}|^<\d+>|^\d+[^\d]")  # ← 先頭が数字なら匿名化とみなす
```

九州電力送配電の様式5は「**1北九州**」「**26山家**」のように**連番＋実名**で書かれている。
`^\d+[^\d]` がこれを匿名化と判定して、照合前に全部捨てていた。
実際には端点ラベル 46 種のうち **25 種は番号を剥がすだけで OSM の変電所名と一致**する。

### 修正

- `ANON_RX` から `^\d+[^\d]` を削除（真の匿名化 `□□□□` と `<12>` のみ残す）
- `with_seq_stripped()` を追加し、先頭連番を剥がした候補で照合する
- ついでに入出力を `AGJ_DISCLOSURE_NORM` / `AGJ_DISCLOSURE_OUT` で差し替え可能にした
  （`data/external/` は .gitignore なので、リポジトリ外のデータで回せるようにする）

### 効果（実測）

| 指標 | 修正前 | 修正後 |
|---|---:|---:|
| 両端解決 | 411 | 423 |
| **評価対象（弦>0.5km & X>0）** | **109** | **270** |
| **評価に入った事業者** | **6 社** | **10 社（全社）** |
| **Ybus カバレッジ** | **0.55%** | **1.37%** |
| 比の中央値 | 1.241 | **1.202** |

**東北が 0 → 74 本**、中部 0 → 30、沖縄 0 → 12、九州 0 → 4 と、
これまで丸ごと評価から外れていた事業者が入った。
**中央値は 1.24 → 1.20 とほとんど動かない** ＝ 母集団が 2.5 倍になっても結論は変わらない（頑健）。

## 5. まだ残っている問題

- **外れ値に誤マッチ**: 比 <0.5 または >2.5 が 28 本（10%）。
  例: chugoku 110kV で弦距離 167km（110kV でこの距離は不自然＝両端の対応付けが誤り）
- **未解決 746 端点の大半は `unknown`** ＝ モデル（OSM）側に該当変電所が無い。
  これは #38（OSM への逆貢献）の領域で、照合ロジックでは埋まらない
- **OCCTO から追加取得**（オーナー提案）: 系統情報サービスは登録制。
  ただし**追加取得より先に、手持ち 1,009 本の歩留まり**（現状 270/1,009 = 27%）を上げる方が効く

## 6. 次の一手

1. 他社の匿名化パターンも同様に解読できないか（沖縄 21% / 中国 27% が低い）
2. 誤マッチ検出: 弦距離と電圧階級の物理的整合（110kV で 167km は棄却）をチェックに入れる
3. `unknown` 端点を #38 の OSM 逆貢献リストに合流させる
4. OCCTO の系統情報サービス（登録制）で、様式5以外に設備諸元が取れるか調査


## 4.5 ★ 誤マッチが大量に混入していた（オーナー指摘・2026-08-19）

§4 の修正直後は「評価 270 本・Ybus 1.37%」と報告したが、**これは誤マッチ込みの数字だった**。
オーナーが地図を見て「直線ひどいのがさらに出てきた」と指摘。実際、東北を縦断する
濃紺（比 0.1 前後）の長大直線などが現れていた。

原因は **同名異所**。名前が `exact` 一致でも、同名の変電所が全国に複数あると別地点に解決される。
`ANON_RX` を緩めて母集団を増やしたぶん、この誤マッチも増えていた。

### 追加した 2 つの物理チェック（`compare_observed_derived_impedance.py`）

1. **弦距離の上限**（`SPAN_LIMIT_KM`）— 電圧階級として現実的な亘長を超える対応付けを棄却。
   7 本棄却: 阿武隈幹線 466km / 高津線 438km / 西福島線 417km / 吾妻幹線 405km ほか
2. **幾何の矛盾**（`RATIO_FLOOR = 0.5`）— 実線長 ≥ 弦距離 なので線種が合っていれば比 ≥ 1 が原則。
   比が 0.5 を割るのは「モデルの弦距離が実線長の 2 倍超」を意味し幾何的に説明できない。
   14 本棄却: 仙台泉線 0.06 / 豊根連絡 0.09 / 福島東幹線(山) 0.17 ほか。
   **地中線は除外**（架空線の標準値で比べると比が下がるのは線種違いであって誤マッチではない）

棄却された線の `match_level` は `contains/contains` `contains/national` に偏っており、
**弱い照合レベルが誤マッチを生んでいる**ことが裏付けられた（#47 の改善項目）。

### 最終的な数字

| 指標 | 修正前 | 照合修正後（誤マッチ込み） | **誤マッチ除去後** |
|---|---:|---:|---:|
| 評価対象 | 109 | 270 | **249** |
| 事業者 | 6 社 | 10 社 | **10 社** |
| Ybus カバレッジ | 0.55% | 1.37% | **1.26%** |
| 比の中央値 | 1.241 | 1.202 | **1.228** |

**誤マッチは比を押し下げていた**（1.202 → 除去後 1.228）。真の改善は 109 → 249 本（2.3 倍）。

### 教訓

数字（カバレッジ 2.5 倍）だけ見て「改善した」と報告したが、**地図に描いて初めて誤マッチが見えた**。
[[feedback-verify-before-claiming]] の「原理の違う第二経路で確認」を、
今回は**可視化**が担った。カバレッジを増やす変更は、必ず地図で確認する。

## 7. 線名照合による独立検証（#47・オーナー承認 2026-08-19）

「棄却は暫定処置。OSM とモデルの**線名**を見れば正しい対応付けに直せる」という
指摘を受けて、第二の照合経路を実装した（`scripts/verify_crosswalk_by_linename.py`）。

**公表の line_name → built の同名エッジ群 → その両端** で対応付けを検証する。
線名は変電所名より一意性が高いので、同名異所に強い。
これ自体は crosswalk もモデルも書き換えない（OBSERVED_VS_DERIVED の規約）。

### 結果（公表 1,009 本）

| 判定 | 本数 | 意味 |
|---|---:|---|
| **agree** | **162** | 変電所名照合と線名照合が**一致** ＝ 対応付けが独立に裏付けられた |
| no_line | 592 | 線名がモデルに無い（OSM 未収載＝#38 の領域） |
| unresolved | 196 | 既存が両端未解決 |
| ambiguous | 28 | 線名側が広がりすぎ（`A線;B線` の複合名を束ねている等） |
| **fixable** | **9** | 線名の方が明らかに短い ＝ **既存が誤マッチ** |
| generic_name | 22 | 「他社線」等の汎用名で照合不能 |

### 正せる 9 本

| 線 | 既存の弦距離 | 線名照合 |
|---|---:|---:|
| 高津線1L (関西154kV) | 438.6 km | **5.7 km** |
| 西上武幹線1L/2L (東京500kV) | 92.5 km | 40.6 km |
| 奥羽幹線 (東北275kV) | 72.5 km | 12.6 km |
| 新栃木線1L/2L (東京500kV) | 65.8 km | 7.1 km |
| 中新潟線 (東北154kV) | 25.3 km | 13.3 km |
| 新筑波線1L/2L (東京500kV) | 19.5 km | 8.8 km |

### 注意（線名照合も万能ではない）

- **汎用名は使えない**: 北海道 187kV「他社線1L」が 0.38 km の無関係な線に当たった。
  `GENERIC_NAMES`（他社線・連絡線・引込線・本線・支線 …）を除外している
- **奥羽幹線 72.5→12.6 km** のように、線名側が路線の一部しか拾えていない疑いもある。
  `fixable` は「食い違いの検出」であって、**どちらが正しいかは個別に見る必要がある**
- 最大の成果は 9 本の修正候補より **162 本が独立に裏付けられたこと**。
  変電所名という 1 本の経路だけで信じていた対応付けに、二本目の根拠がついた

## 8. fixable 9 本を地図で個別確認（2026-08-19）

図: `figs/linename_fixable.png`（赤破線＝いまの対応付け／青＝線名照合が指すエッジ群）

### 分かったこと: **`fixable` の判定基準が誤っていた**

`span < chord × 0.6`（線名の実体が短ければ既存が誤マッチ）としたが、地図で見ると
**多くは「モデルに線名が部分的にしか付いていない」だけ**だった。西上武幹線は青が赤破線に
**並走**しており、既存の両端は正しく、モデルが線の一部にしか名前を持っていない。

自動判定も試みた（線名エッジ群の各点から既存 from–to 線分への距離の中央値）が、
**閾値を chord 比にすると長い誤マッチほど緩くなる**という欠陥があり、
高津線 438km が「沿っている＝既存が正しい」と誤判定された。絶対値閾値にすると
今度は西上武幹線（並走しているのに 5.2km 離れている）が誤判定される。

**方向の一致まで見ないと自動判定は精度が出ない。現時点では図で人が見るのが確実。**

### 図から読める暫定判定（人手・要検証）

| 線 | 図で見えること | 暫定判定 |
|---|---|---|
| 高津線1L (関西154kV) | 赤が関西→関東 438km、青は関西側に 5.7km | **既存が誤マッチ**（物理チェックでも棄却済み） |
| 新筑波線1L/2L (東京500kV) | 青が赤の端から**別方向**へ伸びる | **既存が誤マッチの疑い** |
| 西上武幹線1L/2L (東京500kV) | 青が赤に**並走**（同方向・同範囲） | 既存が正しい（線名が部分） |
| 中新潟線 (東北154kV) | 青が赤に沿って蛇行 | 既存が正しい（線名が部分） |
| 新栃木線1L/2L (東京500kV) | 青は赤の端の 7km のみ | 既存が正しい（線名が部分） |
| 奥羽幹線 (東北275kV) | 青は赤の北端の一部のみ | **判定困難**（奥羽幹線は実際に長い） |

### 結論

- **線名照合の本当の価値は `fixable` ではなく `agree` 162 本**（対応付けが独立に裏付けられた）
- `span_km` は「その名前を持つエッジの範囲」であって「線の全長」ではない。
  モデルの線名カバレッジが部分的なので、短いこと自体は誤マッチの証拠にならない
- 誤マッチの確実な検出は**物理チェック**（電圧に対する亘長・幾何矛盾）の方が効いた
- 残る個別確認は人手。図があるので判断はできる状態にした

## 9. 地図を「実線形」で描き直した（オーナー指摘 2026-08-19）

> 地図が直線すぎるのであまり嬉しくない。そして400本くらいあるのであればもっと充実できるのでは？

§2 の地図は公表線の from→to を**直線**で結んでいたため、モデルが実線形を持っているのに
地図が直線だらけになっていた。**モデルのグラフ上で両端をつなぐ経路を Dijkstra で探し、
その実線形を描く**ようにした（`scripts/plot_impedance_routed_map.py`）。

- **両端解決 423 本のうち 402 本（95%）はモデル上の経路が取れた** → 実線形で描画
- 経路が取れないのは 4 本だけ（点線＝線形が未収載）
- 同名異所の誤マッチ 7 本は描画から除外（#47 の物理チェックと同じ基準）
- 比は「並列重複除去後の代表 1 本」にしか付いていなかったので、**回線番号を落としたキーで
  1L/2L 全回線に配った**（灰色＝比が無い線がほぼ消えた）

結果、**公表インピーダンスで裏が取れている範囲が全国の基幹網として浮かび上がる**図になった。
地域差も読める: 東北・関東は青（比 1.0–1.2）、中国・四国・北海道は赤（1.4 以上）。

図: `figs/impedance_routed_map.png`
