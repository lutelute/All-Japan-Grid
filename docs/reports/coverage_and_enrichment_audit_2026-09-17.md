# 収録率とタグ補完率の実測監査（2026-09-17）

オーナー指摘「OSM にあるといっている点や線の収録でも 100% ではないはず」「タグの補完率 87% の内訳が欲しい」
を受けた実測。スライド化用に数値だけを並べる。**すべてこの監査で計算した一次値**で、
論文の記載値をそのまま写したものは「論文」と明記した。

### 1.3 収録率

一意 osm_id ベース（重複を除いた実オブジェクト数 ÷ OSM 実在数）:

| レイヤ | 手元（一意） | OSM 実在 | 収録率 |
|---|---:|---:|---:|
| 線路（line+cable） | 33,463 | 34,134 | **98.0%** |
| 変電所 | 6,146 | 6,342 | **96.9%** |
| 発電所 | 14,210 | 19,727 | **72.0%** |
| 発電所（osm_id なし 2,581 を加算） | 16,791 | 19,727 | **85.1%** |

**要点**

- 線路・変電所は 97〜98%。**100% ではない**が、取りこぼしは 2〜3% 程度。
- 発電所は 72〜85% と明確に低い。
- 比較の限界: OSM 側は日本全土、手元は 10 地域 bbox の union。離島や bbox 外は
  OSM 側にのみ計上される。取得時点も一致していない（手元は取得時のスナップショット、
  OSM 側は 2026-09-16）。したがって収録率は**上下 数ポイントの誤差を含む目安**。

### 1.4 公称値は重複を含む

論文・データセットの公称値「送電線 40,077 / 変電所 6,962 / 発電所 19,138」は**延べ件数**で、
地域 bbox の重なりによる同一 OSM オブジェクトの二重計上を含む。

- 線路 6,547 件、変電所 1,083 件、発電所 2,338 件が複数 region に重複
- 重複を除いた実オブジェクト数は 線路 33,463 / 変電所 6,146 / 発電所 14,210(+osm_id なし 2,581)
- 公称値と実オブジェクト数の差は 線路 **-16.5%**、変電所 **-15.1%**

## 2. 取得対象外のタグ

抽出クエリは `power=substation` / `power=line` / `power=cable` / `power=plant` の 4 種のみ。
OSM に存在するが**最初から取りに行っていない**電力インフラがある。

| タグ | 日本の実在数 | 扱い |
|---|---:|---|
| `power=minor_line` | **2,815**（way 2,815） | 対象外（配電線） |
| `power=generator` | **154,615**（node 8,733 / way 145,882） | 対象外（発電ユニット単体。plant の内側や単独の屋根置き PV など） |
| `power=tower` | **251,216**（node） | 対象外（鉄塔）※別途 `data/osm_raw_towers/` に一部取得あり |
| `power=transformer` | **2,694**（node 2,643 / way 51） | 対象外（変圧器ノード） |

`power=generator` は `power=plant`（19,727）の **約 7.8 倍**ある。OSM では発電所の外形を `plant`、
その中のパネル列・号機を `generator` で描く流儀が一般的だが、**`plant` で囲まれていない単独の
`generator`（屋根置き PV など）は本データセットに一切入らない**。発電所の収録率（§1.3 の 72〜85%）
をさらに下回る実効的な取りこぼしがここにある可能性が高い（plant 外の generator の件数は未計測）。

`power=tower` 251,216 基は、線路形状の頂点として間接的には使われているが、鉄塔オブジェクトとしては
取り込んでいない。

加えて、取得したもののうち `min_voltage_kv = 22.0`（`build_network_snapped`）で
**既知電圧 22 kV 未満の線路はモデル構築時に除外**される。電圧不明（0）は残す。

## 4. スライドに載せるなら（要点3行）

1. **収録率は 100% ではない** — 線路 98.0% / 変電所 96.9% / 発電所 72〜85%（Overpass 実測との比較）。
   さらに公称値は地域 bbox の重なりによる重複を含み、実オブジェクト数は線路で -16.5%。
2. **取りに行っていない設備がある** — `generator` 154,615・`tower` 251,216・`minor_line` 2,815・
   `transformer` 2,694 は対象外。`generator` は `plant` の約 7.8 倍あり、plant 外の単独設備は丸ごと抜ける。
   モデル構築時にはさらに 22 kV 未満を除外。
3. **補完 87% の中身はほぼ名称** — 補完で書き込まれた属性値 88,951 件の 94% が `name`。
   事業者は補完後も 32〜50%、設備容量の実記録は 6.7%。

## 再現方法

本レポートの数値は以下で再計算できる。

- 収録率: Overpass に `[out:json];area["ISO3166-1"="JP"][admin_level=2]->.jp;(way(area.jp)["power"="line"];);out count;`
  （User-Agent 必須。無いと 406）／手元は `data/*.geojson` の features 数と `osm_id` の一意化
- 補完内訳: `data/grid.db` の `enrichments` を `field` / `source` で GROUP BY、
  `field NOT LIKE '\_%'` でメタと実属性を分離
- 欠損充足: `raw_features.tags`（JSON）で空の feature_key 集合と、`enrichments` の
  当該 field を持つ feature_key 集合の積
