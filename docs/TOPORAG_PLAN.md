# topoRAG × All-Japan-Grid 適用計画

**topoRAG**（回路のネットリストを、素子種の 1/0・個数でベクトル化しコサイン類似度で
「似ている/似ていない」を判定する手法。回路読解実験で実証済み）を、送電網グラフに
一般化する計画。2026-08-08 起案。

## なぜ効くと考えるか

送電網の変電所照合は現状 2 経路しかなく、どちらも今日の裁定で限界が実証された:

| 照合手段 | 限界（実測） |
|---|---|
| 名前一致 | keitouzu crosswalk で **name_t1_national 32件中12件・name_t3_national 5件中4件が誤マッチ**（同名異地）。関西は全站匿名で名前が存在しない |
| 座標一致 | keitouzu は座標を持たない。関西の座標カバー 25%・地下変電所は地図に無い |

第三の経路が**構造**。変電所は「電圧階級・変圧器・接続線・隣接局」という
ネットリスト同様の離散構造を持ち、これはレイアウト不変・名前不要・座標不要。
上流も厳密 3 隣接一致（`topology` 法）で 13 件同定しており、原理は既に動いている。
topoRAG のソフト類似度はこれをスケールさせる。

## ベクトル設計（案）

変電所 s の特徴ベクトル v(s) — すべて built DB / keitouzu CSV の両方から計算可能:

- **電圧階級の 1/0**: {500, 275, 220, 187, 154, 132, 110, 77, 66, DC/FC} の保有
- **階級別次数（個数）**: kV 層ごとの接続線本数
- **変圧器リンク数**: @kv 層間接続の個数（= 変電所内の電圧変換段数）
- **1-hop 隣接プロファイル**: 隣接局の電圧階級ヒストグラム
- **2-hop 集約**: 隣接局の次数の {min, median, max}（WL 反復 1 回に相当）
- **kind**: substation / switching / converter / plant 併設の 1/0

比較は**同一電圧宇宙への射影後**に行う（keitouzu は基幹+154kV のみなので、
built 側も同じ階級集合に制限してから次数を数える。射影せず比較すると
built の 66kV 下位網の次数がノイズになる — crosscheck の sub_adj 構築コードを再利用）。

## フェーズ計画

### Phase 0 — 「系統を読めるか」実証実験（1セッション）

回路実験の追試を系統でやる。**ground truth に crosswalk 検証済み 641 対応**を使い、
keitouzu 側ベクトルから built 側の同一站を検索できるかを測る。

- 実験: keitouzu の各站 → built 全站（同 region 内）とのコサイン類似度 → top-1/top-5 に
  正解が入る率
- 成功基準: region 内 top-5 recall ≥ 70% で Phase 1 へ。50% 未満なら特徴設計を再考
- 副産物: 類似度が名前一致と矛盾する対応 = crosswalk 誤マッチの第三の検出器
  （今日の 16 件がネガティブコントロールになる — 誤マッチは構造類似度が低いはず）

### Phase 1 — 関西の匿名站実名化（実利・本命）

関西 150 站は図上符号のみ・座標カバー 25% で「系統解析に使えない」と上流が明言。
構造ベクトルで keitouzu 匿名站 ↔ built 関西站を照合する。

- 評価: 上流が deanon 済みの関西 47 站を held-out ground truth に
- 出力は**候補提示のみ**（similarity + 根拠の特徴差分を添えて裁定キューへ。
  自動採用しない — 家訓「梃子候補は人間判断」）
- 成功すれば: 関西座標カバー 25% → 50%+、crosswalk 拡張を上流へ還元（issue #1 の続き）
- 同型の適用: 中国の匿名 18 站・未対応 694 站のうち実名 224 站

### Phase 2 — 構造外れ値スクリーニング（品質診断器）

電圧階級ごとに站ベクトルをクラスタし、セントロイドからの距離を外れ値スコアに。

- 検証: 既知の欠陥集合（孤立站・電圧整合未解決 4 站・断絶 69 本の端点）が
  外れ値上位に濃縮されるか（enrichment 検定）
- 濃縮されるなら `ajgrid validate` 系に組み込む新しい診断計器になる

### Phase 3 — 研究展開（toporag 論文との接続）

- **縮約の指紋**: 縮約前後で近傍ベクトルの保存度を測る = 「帳簿付き集約」の
  定量検証器（縮約とリアリティ方針の計器化）
- **地域構造の特徴づけ**: region 別ベクトル分布で日本の系統構造様式を分類
  （187kV 四国・110kV 九州など階級構成の個性が既にベクトルに写る）
- 論文角度: 「回路→送電網へのネットリスト類似度の一般化と、
  実在 2 独立ソース（OSM由来 vs 公式系統図由来）での照合実証」

## しないこと

- ベクトル類似度による接続・対応の**自動採用**（スクリーニングと根拠提示まで）
- 潮流計算の代理としての類似度（Phase 3 の研究課題に留める）

## データの所在（すべて手元にある）

- built グラフ: `docs/data/built/all.json`（sub_adj 構築は `scripts/keitouzu/crosscheck_keitouzu.py` 再利用）
- keitouzu グラフ: `data/external/keitouzu/`（fetch スクリプトで再物質化）
- ground truth: crosswalk 641 対応 + 沖縄官略号対照表 + 関西 deanon 47 站
- ネガティブコントロール: `keitouzu_xwalk_adjudication_2026-08-08.json` の除外 16 対応
