# topoRAG × All-Japan-Grid 適用計画

**topoRAG**（回路のネットリストを、素子種の 1/0・個数でベクトル化しコサイン類似度で
「似ている/似ていない」を判定する手法。回路読解実験で実証済み）を、送電網グラフに
一般化する計画。2026-08-08 起案。

## なぜ効くと考えるか

送電網の変電所照合は現状 2 経路しかなく、どちらも今日の裁定で限界が実証された:

| 照合手段 | 限界（実測） |
|---|---|
| 名前一致 | keitouzu crosswalk で **name_t1_national 32件中12件・name_t3_national 5件中4件が誤マッチ**（同名異地）。関西は全変電所が匿名で名前が存在しない |
| 座標一致 | keitouzu は座標を持たない。関西の座標カバー 25%・地下変電所は地図に無い |

第三の経路が**構造**。変電所は「電圧階級・変圧器・接続線・隣接局」という
ネットリスト同様の離散構造を持ち、これはレイアウト不変・名前不要・座標不要。
上流も厳密 3 隣接一致（`topology` 法）で 13 件同定しており、原理は既に動いている。
topoRAG のソフト類似度はこれをスケールさせる。

## ベクトル設計（案）

変電所 s の特徴ベクトル v(s) — すべて built DB / keitouzu CSV の両方から計算可能:

- **電圧階級の 1/0**: {500, 275, 220, 187, 154, 132, 110, 77, 66, DC/FC} の保有
- **階級別次数（個数）**: kV 層ごとの接続線本数
- **変圧器リンク数**: @kv 層間接続の個数（= 変電所内の電圧変換段数）
- **1-hop 隣接プロファイル**: 隣接局の電圧階級ヒストグラム
- **2-hop 集約**: 隣接局の次数の {min, median, max}（WL 反復 1 回に相当）
- **kind**: substation / switching / converter / plant 併設の 1/0

比較は**同一電圧宇宙への射影後**に行う（keitouzu は基幹+154kV のみなので、
built 側も同じ階級集合に制限してから次数を数える。射影せず比較すると
built の 66kV 下位網の次数がノイズになる — crosscheck の sub_adj 構築コードを再利用）。

## フェーズ計画

### Phase 0 — 「系統を読めるか」実証実験 ✅ **実施済み（2026-08-08）**

結果の正本は **[`docs/reports/toporag_phase0_2026-08-08.md`](reports/toporag_phase0_2026-08-08.md)**。

- **判別は成立**: 名前も座標も使わず、検証済み対応（正例640）と誤マッチ確定（負例16）を
  **AUC = 0.888** で判別。ランダム対照 0.150 に対し正例中央値 0.919 で空間は縮退していない
- **検索は当初基準に未達**だが、層別すると像が変わる: 全体 recall@5 = 18.4% は
  平凡な通過局が母数を占めるための平均で、**次数6+ のハブでは recall@5 = 49.4%**（次数1 の 6.2% の8倍）
- **判定**: 当初の「top-5 recall ≥ 70% で Phase 1 へ」は未達。ただし**ハブ限定なら実用圏**という
  層別の知見が得られたため、Phase 1 は「全変電所を一括で同定」から**「ハブから錨を打ち周辺へ広げる」**
  設計へ変更して続行する
- **WL 反復は効かない**（recall@5 18.4% → 18.9% → 16.9%）。近傍集約は誤マッチとの分離は
  進めるが個体識別に寄与せず、2周目は悪化。ソース間で近傍の見え方が違う（built は下位網を持ち
  keitouzu は持たない）ため深い集約は差を増幅する側に働く。**負の結果として記録**
- **副産物**: ①正典の跨 region 重複変電所 **884 組**を発見（`all.json` は地域ファイルの単純連結で
  境界設備が二重計上）②突合コードの座標解決バグを発見・修正（610 変電所が隣接グラフから
  脱落していた。訂正後 整合率 83.5% → **88.1%**、食い違い 127 → **92**）

### Phase 1 — 関西の匿名変電所実名化（実利・本命）

**Phase 0 の層別結果を受け、「ハブから錨を打つ」設計に変更**（全変電所を一括で同定はしない）。
関西の 150 変電所は図上符号のみ・座標カバー 25% で「系統解析に使えない」と上流が明言。
構造ベクトルで keitouzu の匿名変電所と built の関西変電所を照合する。

1. 高次数の変電所（次数6+）から候補提示 — この層は recall@5 ≈ 50% で実用圏
2. 確定したハブを既知点として、隣接制約（確定済み隣接の一致本数）を加えた再照合を回す
   — 上流の `topology` 法（厳密3隣接一致）のソフト版にあたる
3. 低次数の通過局は構造単独では同定しない（原理的に不可能と Phase 0 で判明）

- 評価: 上流が実名化済みの関西 47 変電所を held-out ground truth に
- 出力は**候補提示のみ**（similarity + 根拠の特徴差分を添えて裁定キューへ。
  自動採用しない — 家訓「梃子候補は人間判断」）
- 成功すれば: 関西座標カバー 25% → 50%+、crosswalk 拡張を上流へ還元（issue #1 の続き）
- 同型の適用: 中国エリアの匿名変電所 18 件、および未対応 694 件のうち実名を持つ 224 件

### Phase 2 — 構造外れ値スクリーニング（品質診断器）

電圧階級ごとに変電所ベクトルをクラスタし、セントロイドからの距離を外れ値スコアに。

- 検証: 既知の欠陥集合（孤立変電所・電圧整合が未解決の 4 変電所・断絶 69 本の端点）が
  外れ値上位に濃縮されるか（enrichment 検定）
- 濃縮されるなら `ajgrid validate` 系に組み込む新しい診断計器になる

### Phase 3 — 研究展開（toporag 論文との接続）

- **縮約の指紋**: 縮約前後で近傍ベクトルの保存度を測る = 「帳簿付き集約」の
  定量検証器（縮約とリアリティ方針の計器化）
- **地域構造の特徴づけ**: region 別ベクトル分布で日本の系統構造様式を分類
  （187kV 四国・110kV 九州など階級構成の個性が既にベクトルに写る）
- 論文角度: 「回路→送電網へのネットリスト類似度の一般化と、
  実在 2 独立ソース（OSM由来 vs 公式系統図由来）での照合実証」

## しないこと

- ベクトル類似度による接続・対応の**自動採用**（スクリーニングと根拠提示まで）
- 潮流計算の代理としての類似度（Phase 3 の研究課題に留める）

## データの所在（すべて手元にある）
