ダッシュボード潮流マップ（詳細）データを使う

日本の送電網、いま

各社が公表した実績需要に合わせて、全国の送電網の潮流を毎時計算し直しています。 その結果を、線の明るさと光の粒の流れで 1 枚にしました。約 140KB で開きます。 線ごとの詳しい値や観測方向との照合は 潮流マップ（詳細） へ。

見方

  • 線の明るさと色は潮流の大きさです（電圧階級ごとの目安容量に対する割合。青緑→琥珀→朱）。
  • 光の粒は潮流の向きに流れます。粒が多く速いほど、流れが大きい線です。
  • 点線は 50Hz と 60Hz のおおよその境界です。琥珀の輪は周波数変換所と北海道・本州間連系線で、下の行に流れる向きと量を出します。
  • 沖縄は左上に差し込み図として移しています。エリア名の GW は、いまの時刻の実績需要です。
  • すべて OSM 由来のモデルでの推定値で、実際の運用値ではありません（何が推定か）。

ほかのサイトに貼る

<div class="ajg-pulse"></div>
<script src="https://lutelute.github.io/All-Japan-Grid/js/pulse.js" defer></script>
data-langja / en（既定はページの言語）
data-controlsfalse で時刻の操作を隠す
data-labelsfalse でエリア名を隠す
data-srcpulse.json の場所（既定はこのサイトのもの）

部品の下に出る「推定値」と「© OpenStreetMap contributors」の表記は消さないでください（ODbL の表示義務）。

データ

data/flow_map/pulse.json は scripts/export_pulse.py が毎時書き出します。 187kV 以上の線に今日の 24 時刻の潮流を付け、110kV 以上の線を下地として、形を約 400m で間引いています。 形式はスクリプトの冒頭に書いてあります。
