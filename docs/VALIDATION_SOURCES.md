# 外部正解データ調査 — 送電網トポロジ・潮流の検証ソース

**調査日**: 2026-06-10（Web実調査・実ダウンロード検証済み）/ **モデル**: Claude Fable 5
**目的**: OSM由来モデルの精度を「権威データとの照合」で定量化するためのソース台帳。

> **訂正**: 旧メモの「国土数値情報C02=電力施設」は**誤り**（C02=港湾）。
> KSJに送電線・変電所データセットは過去含め存在しない。エネルギー系はP03(発電施設, 2013)のみ。

## 利用可能な正解ソース（有用度順）

### 1. 一般送配電事業者の空容量マッピング（機械可読・即利用可）

| 事業者 | 形式 | 内容 | URL |
|---|---|---|---|
| **関西電力送配電** | **CSV** (CP932, ほぼ毎日更新) | ≥154kV送電線: 線路名・電圧・**回線数**・設備/運用容量(MW)・予想潮流 | `kansai-td.co.jp/interchange/takusou/pdf/154kv_more_line.csv`（変圧器版 `_trans.csv`、地図 `_mapping.pdf`） |
| 東京電力PG | PDF | 基幹系統・県別予想潮流 | `tepco.co.jp/pg/consignment/system/` |
| 全社一覧 | - | エネ庁リンク集 | `enecho.meti.go.jp/category/saving_and_new/saiene/grid/07_map.html` |

→ **実装済み**: `src/validation/external_match.py`（`python -m src.validation.external_match kansai --csv ...`）。
**初回計測 (2026-06-10, 関西)**: 公式235線中 名前一致40%（厳密17.9%）・**500kV 34線中20線が名前で発見不可**・
一致線の電圧一致95%・**circuits タグ一致56%**。
注意: これは「名前で見つかるか」の下界。OSMの命名流儀差（幹線/新◯◯線等）があるため、
真の幾何recallには地理院タイル等での幾何照合が必要。

### 2. 東京電力PG 潮流実績CSV（変電所×線路名つき時系列 = トポロジ+潮流の正解）

- `tepco.co.jp/pg/consignment/system/` →「地点別需要・系統潮流実績」
- **基幹(275kV+)**: `pdf/tyouryu_kikan.zip` → `jisseki_kikan.csv` = **730列（「京浜(変) - 東京南線1・2L」形式の変電所×設備名）× 2024年度通年1時間値潮流(MW)**
- 154kV版 `tyouryu_154kV.zip` / 66kV版 `tyouryu_66kV.zip`（計~50MB）
- **列名だけで「どの変電所にどの線が接続するか」のトポロジ正解になる**。東京エリアの接続検証の本命
- 利用条件: 転載禁止 → data/external/ に置き**再配布しない**（gitignore済み）

### 3. OCCTO 系統情報サービス（全国・30分値）

- 入口: `occtonet3.occto.or.jp/public/...LOGIN_login`（一般公表側は登録不要、全画面CSV保存+一括DL機能）
- **地内基幹送電線潮流実績**: `対象年月日/エリア/電圧(kV)/送電線名/潮流方向/30分毎潮流値(MW)` — 全10エリアの線路名つき実潮流
- **連系線潮流実績**: 運用容量(順逆)/マージン/空容量/計画潮流/**潮流実績(MW)**
- JSアプリのため自動取得は要追加調査（手動DL→data/external/ドロップで運用開始可）
- 全国ゾーナルモデルの連系線潮流の正解はここ

### 4. 国土地理院 ベクトルタイル（OSMと独立な送電線幾何）

- 構造物レイヤ ftCode **8202=送電線**（ズーム14-17）、電子国土基本図由来
- `cyberjapandata.gsi.go.jp/xyz/optimal_bvmap-v1/{z}/{x}/{y}.pbf`（提供実験側で収録確認）
- 出典明示で利用可（政府標準利用規約準拠）→ **幾何ベースのrecall測定**（名前に依らない）の本命

### 5. その他

- **IEEJ標準系統モデル**（EAST30機等）: 無償DL可・再配布不可。縮約模型の妥当性確認用
- **環境省REPOS**: 送電線レイヤは表示のみDL不可。整備手法（数値地図+連系制約マップ）の参考
- **HIFLD日本版は存在しない**（全国送電網の公式GISは非公開 — 本プロジェクトの存在意義）

## ライセンス方針

- 事業者CSV/PDF・OCCTO データ: **リポジトリにコミットしない**（`data/external/` はgitignore済み）。
  取得コマンドをドキュメント化し、照合スコアカード（集計値）のみ `docs/reports/` に記録
- 地理院タイル: 出典明示で利用可。派生統計はコミット可

## 検証ロードマップ

1. ✅ 関西CSV名前照合（`external_match.py`） — recall・circuits一致の初回計測
2. 地理院タイル幾何照合 — 名前に依らない真のrecall（④スナップ改善の効果測定）
3. ✅ 東電 潮流実績CSV列名 → 東京エリアの接続正解照合（`external_tepco.py`、2026-06-10）:
   変電所recall **86.4%**・線路recall 54.2%/81.6%(loose)・**接続ペアrecall 54.9%**
   （名前144+位置13 / 286。初版45.8%→照合ガード3種で改善）。
   照合ガード: **鉄道専業オペレータ名を除外**(57名) / **クラス整合**(基幹275kV+に対し
   低圧同名線はクラス衝突34件として分離) / **位置ベース接続判定**(公式変電所±1.5km、
   東電呼称とOSM名の施設同一性ズレ対策=西北線は稲城(OSM)=北多摩(東電))。
   真の未接続は**41件**。ビルダーがOSM線路名をブランチに保持（項目4の前提）
4. ✅ 東電CSVの**潮流値** vs backboneモデルDC潮流（`external_tepco.py --flows`、2026-06-10）:
   初版=名前一致97線で ρ=0.508 → **照合ガード適用後（鉄道除外+クラス整合）=正味55線で
   Spearman ρ=0.676 (p=1.5e-08)**・中央値倍率0.69。初版の低い相関の一因は
   偽マッチ（き電線・低圧同名線）を比較していたこと。
   残るミスマッチ上位（新袖ヶ浦線の過小=LNG群の発電配置、港北線152MW vs 実測2,420MW等）
   = 本物のモデル課題（発電所配置・並行経路欠落）の固有名詞リスト。
   **負の結果**: ⑤のdegree空間配分はρ改善なし → デフォルトflat維持が検証で確定。
   OCCTO 30分値での他エリア展開は今後
5. OCCTO 連系線実績 vs 全国ゾーナルモデル（`ajgrid solve national` で実行可能に）
