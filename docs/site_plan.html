近い系統 直線距離

候補地を選ぶと、電圧ごとに最寄りの変電所と送電線を出します。

距離は直線です。実際の経路ではありません。送電線は線への垂線の足（線上でいちばん近い点）までの距離です。つなげるか・空きがあるかはここでは分かりません。

AGJ は工事費の単価を持っていません。単価を入れたときだけ「直線距離 × 倍率 × 単価」を掛け算して表に足します。結果は入れた仮定の計算で、見積もりではありません。

倍率の既定 1.12 は、AGJ の正典の線のうち公表インピーダンスと照合できた 246 本で、線形の長さを端点間の直線距離で割った値の中央値です（docs/reports/impedance_validation_2026-08-19.md §10）。新しく引く線がこの倍率になるとは限りません。

出典と注意
  • 系統: All-Japan-Grid の正典（docs/data/built）から書いた地図データ。元は OpenStreetMap（ODbL, © OpenStreetMap contributors）。電力会社の公式情報ではありません。
  • 標高: 地理院タイル（国土地理院）の標高タイル DEM5A・DEM5B・DEM10B。地図を見るときと同じくタイルを読むだけで、点ごとに標高 API を叩きません。
  • 気象: Weather data by Open-Meteo.com（CC BY 4.0）の Historical Weather API、ERA5 再解析。年と月の集計はこのページで行っています。Contains modified Copernicus Climate Change Service information. 欧州委員会と ECMWF はこの情報の利用に責任を負いません。
  • 地名: Nominatim（© OpenStreetMap contributors）。入力のたびには問い合わせず、Enter を押したときだけ、1 秒以上あけて送ります。
  • 潮流実績: 各一般送配電事業者の系統情報の公表（2024 年度）の年統計を AGJ が集計した値（data/flow_map/obs_local.json）。線名だけで引くので、同名の別の区間のことがあります。

接続の可否・空き容量・工事費・工期の判定には使えません。検討は各社の系統情報の公表と事前相談・接続検討で行ってください。
