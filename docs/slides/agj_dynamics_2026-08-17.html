原理 0 系統の数学的正体

系統は1枚の行列 — ノードアドミタンス行列 Y

送電網は「バス(節点)」と「枝(線路・変圧器)」のグラフ。 各枝のインピーダンス z = r + jx の逆数(アドミタンス)を節点方程式に並べたものが Y。

I = Y·V,  Yij = −yij,  Yii = Σyik + yshi
I=節点注入電流・V=節点電圧(複素)。非対角=繋がる枝の−アドミタンス・対角=接続枝+対地分の和。
本モデル: 17,862×17,862・非零0.019%(疎)・回線数parは並列合成でxを1/par倍

電力で書き直すと潮流方程式(ACの基本式):

Pi = Vi Σj Vj (Gij cosθij + Bij sinθij)
G+jB = Y の実部/虚部・θij=位相差。これをNewton–Raphsonで解くのが潮流計算(全4島でAC収束)

この1枚から出るもの

  • 潮流 — どの線に何MW流れるか(観測と突合可能)
  • 短絡容量 — 系統の「強さ」(原理I)
  • 動揺モード — 系統の「揺れ」(原理II)
  • Z(jω) — 周波数依存化すれば共振・受動性(次段)

「インピーダンスだけで系統は基本計算できる」— この直観が正しい理由が上の2式。 あとは発電機(境界条件)と負荷(注入)のモデルを足すほど、見える現象が増えていく。

原理 I 系統の強さ

テブナンの定理で「強さ」を1点の数字にする

バスiから系統を見ると、どんなに複雑な網も 「1つの電源+1つのインピーダンス Zth,i」に等価化できる(テブナンの定理)。

Zth,i = [Y−1]ii ,  Ssc,i = |V|²|Zth,i| ≈ Sbase|Zth,i(pu)|
逆行列は作らず疎LU分解でY x=eiを解いて対角だけ取得(17,862バスでも島あたり数十秒)。 発電機は内部リアクタンスxd″=0.2pu(典型値)で対地アドミタンスとして参加

なぜインバータ電源で重要か

ΔV ≈ Zth·ΔI ,  SCRi = Ssc,iSIBR,i
Zthが大きい(=弱い)ほど、インバータが電流を動かすたびに自分の端子電圧が動く → 制御(PLL)が自分の起こした電圧変動を追いかけて発振する
  • 経験則: SCR < 3 で不安定リスク帯(IEEE系の知見)
  • 66kV系で Ssc≈1〜2GVA が普通の値 — モデルの中央値(0.9〜2.2GVA)はこの帯に整合

原理 II 系統の揺れ

発電機は振り子、送電網はバネ — 動揺方程式

2Hiωs d²δidt² = Pm,i − Pe,i(δ)
Pe,i = Ei Σj Ej(Gij cosδij + Bij sinδij)
δ=回転子角・H=慣性定数[s]・Pm=機械入力・Pe=電気出力。 G,BはYを発電機内部ノードへ縮約(Schur補元 Yred=YGG−YGLYLL−1YLG)した値

小さな揺れに線形化 → 固有値問題

M Δδ̈ = −K Δδ ,  Kij = ∂Pe,i∂δj = EiEj(Bij cosδij − Gij sinδij)
M−1K の固有値 λk → fk = √λk2π , 固有ベクトル = モード形(揺れの向き)
バネ-質点系と完全に同型。K=同期化トルク(バネ剛性)・M=慣性。 運転点(収束ACのE∠δ)込みで評価
Hagg = ΣHiSiΣSi ,  1x″agg = Σ1x″i ,  E∠δ = V + jx″d·I
機械集約: 容量加重H・xd″並列合成。この一手が「FIT極小機の慣性アーティファクト」を根治した (集約前は11〜2,284Hzの非物理・集約後に0.4Hz帯が現れた)

方法論 トポロジをどう作ったか

EGGC — 証拠ゲート付き系統コンフレーション

公表資料で確定した「論理接続(直線)」を、OSMの「物理線形」へ写像する手法。 核心は採否を証拠でゲートすること:

off-main比率 = 経路中の「宙に浮いた断片」の長さ経路の総延長
≥0.7 → 断片こそ公表線そのもの → 実線形に吸着 / <0.3(別線迂回)や経路なし → 直線を保持=存在しない線形を捏造しない

系譜: HMMマップマッチング(Newson & Krumm 2009)・地図コンフレーション(Saalfeld 1988)・ GridKit系(OSM→トポロジの逆方向)。公表論理エッジを入力とし検証可能な採否基準を持つ点が新規。

誠実性

滑らかさは、検証の証拠ではない

完成品の見栄えは「仮定を重ねた推定」を「実在の観測」と誤認させる。 だからこのモデルは仮定の全量を1枚の台帳で見えるようにしている。

  • 介入台帳接続・値・配分を作る介入は30件すべてを ①根拠 ②帳簿 ③無効化手段 の3点セットで登録(登録なき介入は禁止)
  • 出典必須容量・接続は出典URL+原文引用がないものをREJECT。動的定数(H, xd″)は「型式別典型値・個別実測でない」ことを列で明示
  • 負の結果失敗・棄却した仮説も検証図つきで報告に残す
  • A/B保留効果が測れない改良は採用しない(例: 地点需要ピン留め=害なし・カバレッジ0.3%で保留)
  • 近似の明示長軸振動は「帯と形の再現」— 減衰率の定量にはAVR/PSS/ガバナの制御系モデルが要る(未実装と明記)

次に足す数式 — インピーダンス比のナイキスト判定

Middlebrook(1976)→Sun(2011)の系統連系版。系統側ZgridはYbusの周波数依存化 Y(jω)=G+jωL構成から各バスで計算できる — 様式5の実R/X(404線照合済)が効く場所

検証の第5層へ コンセントで系統を測る(PMU)

モデルが予言した0.4Hzを、
壁の100Vコンセントから実測する

周波数と低周波動揺(0.2〜1Hz)は系統全体で共有される量 — 単相100Vの末端でも観測できる(米FNET/GridEyeが壁コンセント計測器で実証)。 GPS/PTPで時刻同期した安価なPMUを分散配置すれば:

台数できる解析
1台周波数イベント検出・df/dtから脱落電源の規模推定
2台長軸振動の位相差=モードの直接観測(九州×関西で0.43Hzのシーソーを見る)・地域間角差=潮流の代理
3台+周波数波の到達時刻差 → 擾乱源の位置標定(三角測量)
10台+モード形の実測地図 → 本モデルの振動地図と直接突合

モデル×実測の閉ループ

モデル(M−1K) → 予言: 0.434Hz・九州⇔関西逆位相 ⇄ PMU実測: f, Δφ(t)
予測したモード周波数・形・(制御系を足せば)減衰率を、自前の観測網で検証できる — 公開データ検証(4層)の上に「自分の計測」という第5層が載る
  • ハード: GPS 1PPS+ADC(Raspberry Pi級で自作可・数千円〜)。単相100Vの位相は配電変圧器の結線分だけずれるが、周波数と動揺成分は共通
  • 解析はこのモデルの資産がそのまま効く: 標定には系統の「電波速度」(慣性密度分布)が要る — 本モデルのM分布から計算できる
