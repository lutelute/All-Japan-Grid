# 800台UCの根拠と実験設計

[explorer.html](explorer.html) をブラウザで開くと、ネットワーク接続なしで閲覧できます。

- 保存済み9件のsolver/controller記録、上下界、制約検証の残差。
- ハッシュが一致した合成800台の入力内訳と4地域接続図。
- 蓄電台数・時間長・容量の増やし方・定式化候補による変数数の算定。
- 制約追加の論点、未測定範囲、未実行の実験案のJSON保存。

再生成はリポジトリのルートから実行します。求解やリモートジョブの送信はしません。

```sh
rtk proxy .venv/bin/python -m scripts.uc_explorer_report
```

元データは `results/` のJSONとsolverログです。入力は
`synthetic_case(800, 24, 17)` を再生成し、保存された入力SHA-256との
一致がない場合は生成を停止します。HTMLには入力とソースのハッシュを埋め込みます。
上下界のグラフはログの記録点で、計算時間や難易度の予測値は含めません。

この作成時点で、記録が参照する `.solution.json.gz` は手元の結果フォルダにありません。
保存された検証レポートの合格と、元解の再検証可能性を別表示しています。
点群の色は入力の燃料種別です。運転状態・SOC・潮流を推測して描いていません。

現行コードのpresolve前binaryは `6 × 800 × T + 4 × B × T`。
削減候補の `6 × 800 × T + B × T` は未実装・等価性未検証です。
SOC関連の制約行数 `(6T + 1)B` は現行の蓄電制約だけの計数で、
追加制約やモデル全体の行数を表しません。

表示検証: Chromiumで9件の記録切替、800点の描画、台数/期間/容量/定式化の変更、
N-1とDCの依存、カバレッジ選択、JSONダウンロードを確認。
1280 / 736 / 390 / 320pxでページ横方向のはみ出しがなく、JavaScriptエラーなし。
