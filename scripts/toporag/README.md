# scripts/toporag — 構造ベクトルによる送電網の類似度

回路のネットリスト類似度（素子種の 1/0・個数 → コサイン）を送電網に一般化した実験器。
計画は [`docs/TOPORAG_PLAN.md`](../../docs/TOPORAG_PLAN.md)、結果は
`docs/reports/toporag_phase0_*.md`。

## 使い方

```bash
cd scripts/toporag
python3 analyze_similarity.py            # Phase 0 実験一式（レポート＋図を生成）
python3 analyze_similarity.py --k 12     # 構造類型のクラスタ数を変える
```

`vectorize_substations.py` は特徴抽出のみのモジュールで、built 正典と
open-keitouzu の**両方から同一の 35 次元軸**でベクトルを作れる。

## 分割単位と特徴軸

「部分」＝ 変電所ひとつのエゴグラフ。

| ブロック | 次元 | 内容 |
|---|---:|---|
| 電圧構成 (1/0) | 10 | 500/275/220/187/154/132/110/77/66/その他 の保有 |
| 階級別次数 | 10 | 各階級での外部接続本数（log1p） |
| 層数・規模 | 2 | 電圧層数（変圧段数の代理）・総次数 |
| 隣接局の電圧 | 10 | 隣接局の最高電圧ヒストグラム |
| 隣接局の次数 | 3 | 隣接局の次数の min/median/max |

## 実装上の注意（踏んだ穴）

- **1座標に複数ノードが載る**。多層站の各電圧層は座標を完全に共有し、さらに地域抽出
  bbox の重なりで跨 region 重複コピーが 884 組ある。座標→単一 ID に潰すと 610 変電所が
  隣接グラフから脱落する（`scripts/keitouzu/crosscheck_keitouzu.py` で実際に踏んだ）。
  **座標にはノード群を持たせ、同一座標のノードは同一物理サイトとして結線する。**
- **変圧器リンクは幾何から復元できない**。層ノードが同一座標のため、同一座標エッジ
  2180 本がどの層ペアを結ぶか特定できない。`n_layers - 1` を代理に使い、独立次元は置かない。
- **評価集合に対する特徴チューニングはしない**。Phase 0 で外したのは復元不能と判明した
  1 次元のみで、性能を見ながらの軸追加はしていない。

## 厳守事項

類似度は**候補提示とスクリーニング**まで。同定の確定・モデルへの反映は人間判断。
