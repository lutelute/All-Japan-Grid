## 2. 取得した原本 (external/, git 無視)

### 2.1 A40 津波浸水想定 (津波防災地域づくり法に基づく都道府県の「津波浸水想定」= 最大クラス (L2) の津波による浸水域と最大浸水深区分のポリゴン)

- URL パターン: `https://nlftp.mlit.go.jp/ksj/gml/data/A40/A40-VV/A40-VV_PP_GML.zip` (VV = 年版 16/17/18/20/21/22/23/24, PP = 県コード)
- 年版と「データの基準となる年月日」: A40-16 = 2016-10-31 時点 / A40-17 = 2017-11-30 / A40-18 = 2018-12-01 / A40-20 = 2020-04-01 / A40-21・22 = 2021-04-01, 2022-04-01 / A40-23 = 2023 年度 (2022-04-01・2021-04-01 時点の県データ; 2023 年度以降は最新年度のデータに統合) / A40-24 = 2024 年度

### 2.2 N03 行政区域 (2026 年版 = 2026-01-01 時点, 2026-04 公開)

- URL パターン: `https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2026/N03-20260101_PP_GML.zip` (26 本, 約 300 MB)

## 3. 年版の選定 (A40) — 「最新版のみ」を既定とし、部分更新の県だけ旧版で補完

`ksj_pipeline/analyze_a40_versions.py` で、複数年版のある 7 県について市区町村 (N03 コード) ごとに各年版の浸水面積 (等積円筒投影で算出) を比較した。

| 県 | 年版 | 面積 km² (新 / 旧) | 旧版のみに浸水域がある市区町村 | 判定 |
|---|---|---|---|---|
| 08 茨城 | A40-23 / A40-16 | 76.0 / 76.4 | 0 | 全域置換 → A40-23 のみ |

## 5. 派生ファイル (derived/)

### 5.1 `tsunami_inundation_A40.gpkg` (EPSG:4326, git 無視, 約 1.5 GB)

| layer | 行数 | 列 | 説明 |
|---|---|---|---|
| `inundation` | 2,430,423 | `pref_code, depth_rank, depth_min_m, depth_max_m, depth_class_src, source_version, geometry(Polygon)` | 原典ポリゴンをそのまま (県側で同一区分の隣接セルは結合済み。不正形状は `make_valid` で修復、件数は付表「A40 県別結果」)。解析の正本 |
| `inundation_dissolved` | 175 | 上記 + `area_km2`, geometry(MultiPolygon) | `(pref_code, source_version, depth_class_src)` で dissolve。県×区分の面積集計や粗い描画用。部分数は原典とほぼ同じなので軽くはない |

- `depth_class_src`: 原典 `A40_003` の文字列そのまま (末尾改行は保持。岡山 A40-16 に改行付きあり)
- `depth_min_m`, `depth_max_m`: 文字列から正規表現で抽出した区間 [min, max)。上限なし (「5m以上」「20m以上」「5.0m～」) は `depth_max_m = NULL`。「～0.3m未満」「0.3m未満」は min = 0.0、「0.01m以上」は min = 0.01
- `depth_rank`: 下記の標準 7 区分に **区間の下限で** 割り当てた整数 (控えめ側。例: 東京・千葉の「1m以上 3m未満」→ 3 (1–2 m)、京都「2m以上 4m未満」→ 4、三重「20m以上 50m未満」→ 7、高知「10–15m」「15–20m」→ 6)。区間そのものは min/max 列に残してあるので、用途に応じて別の割当も可能

| depth_rank | 浸水深 | 備考 |
|---|---|---|
| 1 | 0.3 m 未満 | 県によっては下限 0.01 m |
| 2 | 0.3 m 以上 1 m 未満 | 東京・千葉は 0.3–0.5 / 0.5–1 に細分 |
| 3 | 1 m 以上 2 m 未満 | 東京・千葉は 1–3 m を 3 に割当 |
| 4 | 2 m 以上 5 m 未満 | 多くの県が 2–3 / 3–4 / 4–5 (または 3–5) に細分 |
| 5 | 5 m 以上 10 m 未満 | 上限なし「5m以上」もここ |
| 6 | 10 m 以上 20 m 未満 | 徳島「10m以上」(上限なし) もここ |
| 7 | 20 m 以上 | 三重は「20m以上 50m未満」 |

```python
# 点 (変電所) の浸水深判定 — 原典層を bbox 絞り込みで読むと速い
sub = gpd.read_file(".../tsunami_inundation_A40.gpkg", layer="inundation", bbox=(135.0, 33.0, 136.5, 34.5))
```

### 5.2 `tsunami_inundation_A40_simplified.geojson` — **未出力**

dissolved 層を `simplify(0.0005°)` しても 307.5 MB (指示の 60 MB 上限超) だったため出力していない。理由: 原典が 10–50 m メッシュ由来の微小ポリゴン群 (2.4M 部分) で、simplify では頂点数が減らない。§5.5 の Web 用試作を参照。

### 5.3 `tsunami_inundation_A40_summary.json` (追跡)

県別の採用版・方式・行数・面積・不正形状修復数・区分文字列→(min, max, rank) の対応表・bbox。`make_manifest_tables.py` がこの JSON から本書の表を生成する。

### 5.4 `municipalities.gpkg` (layer `muni`, EPSG:4326, git 無視, 148 MB) / `municipalities_simplified.geojson` (10.5 MB)

- 列: `muni_code` (N03_007, 5 桁), `pref_code` (先頭 2 桁; 仕様外の追加列), `pref_name` (N03_001), `muni_name` (N03_004 + N03_005 = 「神戸市東灘区」のように政令市は区名まで連結。郡名は含めない), `geometry`
- 1,037 行 (26 都府県、政令市は区単位)。`muni_code` 一意。県内で `muni_name` の重複なし
- 簡略版: `simplify(0.002°, preserve_topology=True)` を市区町村ごとに独立に適用 (隣接境界の整合は取っていない → 描画用。面積計算等には gpkg を使う)
- **注意**: 上位の `hazard/nankai/.gitignore` に `data/derived/*_simplified.geojson` があるため、この簡略 geojson は現状 git に載らない (本タスクの指示「小さい派生 geojson は残す」と食い違う。追跡したい場合はその行を外すか `data/.gitignore` に `!derived/municipalities_simplified.geojson` を足す)

### 5.5 `tsunami_inundation_A40_web.geojson` — Web 描画用の試作 (原典忠実ではない)

`ksj_pipeline/build_tsunami_web_geojson.py`: dissolved 層を部分に分解 → 面積 0.0025 km² (50 m 角) 未満の部分を除去 → simplify(0.0005°) → `(pref_code, depth_rank)` で再 dissolve。50 MB 以下に収まった場合のみ残す設計。**結果: 不採用**。部分 2,430,506 → 93,402 に減らしても 52.1 MB で、しかも除去した面積が 545.3 km² (全体の 15.8%) と大きすぎた (浸水域は微小ポリゴンの集まりなので面積を保ったまま軽量化できない)。Web 表示はベクタタイル (PMTiles 等) かメッシュ集計 (例: 250 m メッシュの最大ランク) に切り替えるべきで、本タスクでは未着手。

## 9. 既知の限界・注意

- A40 は各県が津波防災地域づくり法に基づき設定した「最大クラス」の想定で、想定する波源 (南海トラフ巨大地震 M9 クラス、あるいは県独自の複数波源の重ね合わせ) は県ごとに異なる。県間で単純比較する場合は各県の報告書を確認すること
- 年版が 2016 年のままの県 (静岡・三重・和歌山・徳島・愛媛・高知など南海トラフ主要県) が多い。県が改訂していても KSJ に反映されていない可能性がある (例: 静岡県は 2024 年に第 4 次想定の見直しを公表)。最新の県公表値と照合が必要なら県サイトを当たる
- 原典ポリゴンは県側でメッシュ→ベクタ化されており、`inundation` 層 2.4M 行のうち不正形状 (自己接触など) 14,821 行を `make_valid` で修復した (県別内訳は付表「A40 県別結果」)。修復で面積はほぼ変わらない
- 区分の正規化は文字列パーサ (`a40_depth.py`) による。「0.01～0.3m」(大阪 A40-23, m が末尾のみ) の取り違えを 1 度修正済み。新しい県や年版を足したら summary.json の `classes` を必ず目視すること
- `depth_rank` は下限規則なので、上限が標準区分を跨ぐ区分 (東京・千葉 1–3 m 等) では上位ランクの浸水域が過小に見える。厳密には `depth_max_m` を使う
- 兵庫の補完 (merge_muni) は市区町村単位。A40-18 の日本海側 3 市町では A40-16 に浸水域が無く、逆も然りだったので境界問題は生じていない
