# hazard — 地震ハザード

All-Japan-Grid の正典モデルの上で、地震が起きたときの停電と復旧を解く。
1 つの地震を 1 つのプロジェクトとして扱い、設定・データ・レポート・スライド・成果物をその地震のディレクトリにまとめる(計算のコードはいまは南海の中にある)。
All-Japan-Grid 本体(`docs/`・`src/`)には置かない。

| ディレクトリ | 地震 |
|---|---|
| [nankai/](nankai/README.md) | 南海トラフ巨大地震(J-SHIS 最大クラス Mw9.1 + A40 津波)。北海道 2018・福島 2022 のヒンドキャストは南海の手法の検証としてここに含む |

別の地震を始めるときは `hazard/<名前>/` にシナリオ・データ・レポート・スライドを置き、計算のコードは地震ごとに複製しない。
いまのコード(`nankai/src/`)には南海に固定した値が残っている(震源ファイル・地図の中心・破壊開始点など)ので、
2 つ目の地震を始める前に、地震に依らない部分を `nankai/` から切り出す。
