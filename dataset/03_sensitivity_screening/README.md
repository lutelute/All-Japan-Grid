# 03 — 感度行列で系統をスクリーニングする

配布物 `dist/sensitivity/` の **PTDF / LODF** を読み、反復解法を使わずに
行列の掛け算だけで潮流と N-1 を評価する最小例です。

```bash
python 03_sensitivity_screening/screen.py            # 沖縄（最小・数秒）
python 03_sensitivity_screening/screen.py hokkaido
python 03_sensitivity_screening/screen.py west       # 主成分 7,087 バス
```

行列本体は容量が大きいため git に入っていません（west で 339MB）。
無ければスクリプトがその場で生成します（west で約 5 秒）。

## この例が示すこと

| | 計算 | 意味 |
|---|---|---|
| 1 | `flow = PTDF · injection` | 任意の注入パターンから枝潮流。**反復なし** |
| 2 | `flow' = flow + LODF[:,k]·flow[k]` | 枝を1本止めた後の潮流。**DC の枠内では厳密** |
| 3 | `max_j \|PTDF[j,b]\|·1000 / cap_j` | 地点別「1GW 繋いだとき最も混む枝」。**全地点を一度に** |

3 が要点です。同じ答えを潮流の解き直しで得ようとすると地点数だけ反復計算を回すことになり、
西日本（7,087 地点 × AC 1断面 42 秒）では単純計算で 3.4 日かかります。感度行列なら 0.5 秒です。

出力の `screening_{island}.csv` は全地点の混雑感度で、`built_node_id` と座標が付いているので
そのまま地図に戻せます。

## 読むときの注意

- **対象は各島の最大連結成分。** PTDF は連結かつ単一 slack の網でしか定義できません。
  本モデルは島ごとに数百の成分に分かれており、最大成分は需要の約 90% を保持します。
  残りの断片上の地点は行列に含まれません
- **直流近似**（電圧一定・無損失・小角度）。AC 解との枝潮流の差は中央値 0.2〜0.6 MW、
  95 パーセンタイルで 4〜48 MW。**過負荷になりうる枝の絞り込みには十分ですが、
  確定値としては AC で解き直してください**
- **橋（落とすと網が割れる枝）では LODF が定義できません。** 本モデルでは 30〜36% を占め、
  `is_bridge` が立っている枝は N-1 の一括評価から外れます。そこは個別に解く必要があります
- **`capacity_mva` は理論値**（線路は `√3·V·I`、変圧器は銘板）で実運用容量ではありません。
  本モデルでは基準潮流が既にこれを超える枝があり（66kV 層に集中）、
  絶対的な空き容量ではなく**地点間の相対比較**として読んでください
- 参照バス（slack）の列は定義上ゼロになります。「繋いでも影響しない地点」ではなく
  「参照点なので変化を測れない」だけなので、例では比較から除いています

詳しい仕様は `dist/sensitivity/README.md`、実測値は `docs/reports/sensitivity_bench_*.md` と
`docs/reports/hosting_capacity_*.md` にあります。
