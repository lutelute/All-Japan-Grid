距離減衰式（GMPE）hazard_field.GMPEField.median

断層から距離 $X$ の地点で、地震動（最大速度 PGV）がどれだけになるかを、過去の観測記録の回帰で表した式。J-SHIS の実データが無いときの感度ケースに使う。

$$\log_{10}\mathrm{PGV}_{600} \;=\; 0.58\,M_w \;+\; 0.0038\,D \;-\; 1.29 \;-\; \log_{10}\!\big(X + 0.0028\cdot 10^{0.5M_w}\big) \;-\; 0.002\,X$$
PGV₆₀₀Vs=600 m/s の硬い地盤での最大速度 [cm/s]。地表値は増幅率 $A$（既定 1.6）を掛けるM_wモーメントマグニチュード。式は Mw 8.3 程度までの回帰なので有効値 8.5 で飽和させるD断層の代表深さ [km]（20）X断層面までの最短距離 [km]。近似震源域の多角形からの水平距離と深さの合成0.0028·10^{0.5Mw}近距離での飽和項。Mw が大きいほど震源直上でも無限大にならない

なぜ log10 か。地震動は距離とともに幾何減衰（$1/X$ の項 = $-\log_{10}X$）と内部減衰（$-0.002X$、岩の摩擦で失われる）で小さくなる。掛け算の関係は対数を取ると足し算になり、回帰が一次式で書ける。

例: 静岡変電所 500 kV。$X = 27.1$ km, $M_w = 8.5$, $D = 20$。飽和項 $0.0028\cdot10^{4.25} = 49.8$。
$\log_{10}\mathrm{PGV}_{600} = 4.93 + 0.076 - 1.29 - \log_{10}(76.9) - 0.054 = 1.776$ → PGV₆₀₀ = 59.7 cm/s → 地表 PGV = 59.7 × 1.6 = 95.5 cm/s。

1手ずつ: 手 1「地震動場をサンプル」。J-SHIS 場を使うときは、この式の代わりにメッシュ値を引く。

計測震度と PGA への換算pgv_to_intensity / pgv_to_pga_g

$$I \;=\; 2.002 \;+\; 2.603\,\log_{10}\mathrm{PGV} \;-\; 0.213\,(\log_{10}\mathrm{PGV})^2 \qquad\text{（藤本・翠川 2005）}$$ $$\mathrm{PGA}\,[g] \;=\; \frac{\mathrm{PGV}\cdot r(\mathrm{PGV})}{980.665},\qquad r = \mathrm{clip}\big(14 - 3\log_{10}\mathrm{PGV},\;6,\;14\big)\ [1/\mathrm{s}]$$
I計測震度（実数）。4.5〜5.0 が 5弱、5.0〜5.5 が 5強、5.5〜6.0 が 6弱、6.0〜6.5 が 6強、6.5 以上が 7rPGA/PGV 比。大地震の遠方記録は長周期が多く比が小さい（6〜14 1/s）。この換算は仮定で、脆弱性曲線の日本補正と切り離せない

なぜ二次式か。震度は PGV の対数にほぼ比例するが、大きい側で頭打ちになる。二次の項がその曲がりを表す。逆に $I$ から PGV を戻すときは二次方程式の小さい方の根を取る（J-SHIS の震度から PGV を復元するときに使う）。

例（続き）。PGV = 95.5 → $\log_{10}$ = 1.980 → $I = 2.002 + 5.154 - 0.835 = $ 6.32（6強）。$r = 14 - 5.94 = 8.06$ → PGA = 95.5 × 8.06 / 980.665 = 0.79 g。

空間相関ノイズcorrelated_noise

同じ地震でも、地点ごとに地震動は式の値からばらつく。しかも隣り合う地点は同じ方向にばらつく（相関がある）。これを入れないと「隣の変電所が偶然両方壊れる」確率を過小に見積もる。

$$\mathrm{PGV}_i^{(s)} \;=\; \overline{\mathrm{PGV}}_i \cdot 10^{\,\sigma\,\eta_i^{(s)}},\qquad \eta^{(s)} \sim \mathcal N(0,1),\quad \mathrm{Corr}(\eta_i,\eta_j)\ \text{が距離 } 25\,\mathrm{km}\ \text{程度で減衰}$$
σ地震内ばらつき（log10）。J-SHIS 場 0.12、GMPE 場 0.20（＋地震間 0.12 を全点共通に）η粗い格子に白色雑音を置き、ガウス平滑化して補間、分散 1 に正規化した場

なぜ対数正規か。地震動の残差は観測上、対数を取ると正規分布に近い。正の値しか取らないこととも整合する。

例。$\sigma = 0.12$ なら $10^{\pm0.12} = $ ×1.32 / ×0.76。震度に直すとおよそ ±0.3。トレースの手 1 で「6強 1128、7 204 母線」となったのは、期待値場（6強 1030、7 70）にこのノイズが乗った結果。

1手ずつ: 手 1。

脆弱性曲線（対数正規）と停止判定fragility.p_exceed / substation_pout

$$P(\mathrm{DS}\ge k \mid \mathrm{PGA}) \;=\; \Phi\!\left(\frac{\ln(\mathrm{PGA}/\theta_k)}{\beta_k}\right),\qquad \theta_k = \alpha\,\theta_k^{\mathrm{HAZUS}},\ \alpha = 5$$ $$P_{\mathrm{out}} \;=\; \sum_{k=1}^{4}\Big[P(\mathrm{DS}\ge k) - P(\mathrm{DS}\ge k{+}1)\Big]\,q_k,\qquad q = (0,\ 0.3,\ 1,\ 1)$$ $$\text{判定: } u \sim U(0,1),\quad u < P_{\mathrm{out}} \;\Rightarrow\; \text{停止}$$
Φ標準正規分布の累積分布関数θ_k損傷状態 k に「半分の確率で達する」PGA（中央値）。HAZUS の変電所表（≥275 kV: 0.11/0.15/0.20/0.47 g）β_k対数標準偏差。曲線の緩さ（0.35〜0.7）α日本補正。JEAG 5003 の耐震設計と熊本・東北の機能停止率（数%）に合わせて 5q_k損傷状態 k で機能停止する確率。moderate は 3 割、extensive 以上は確実

なぜ対数正規か。「壊れる強さ」が多数の要因の積で決まると考えると、対数を取れば和になり中心極限定理で正規になる。$\Phi$ の中身は「PGA が中央値の何倍か」を $\beta$ で割った標準化変数。なぜ差を取るか。$P(\mathrm{DS}\ge k)$ は累積なので、ちょうど k である確率は隣との差。

例: 275 kV の変電所、PGA = 0.60 g。$\theta\times5 = (0.55, 0.75, 1.00, 2.35)$。$P(\mathrm{DS}\ge k) = (0.569, 0.310, 0.072, 0.000)$ → $P(\mathrm{DS}=k) = (0.259, 0.238, 0.072, 0.000)$ → $P_{\mathrm{out}} = 0.238\times0.3 + 0.072 + 0 = $ 0.144。
トレースの手: 海部開閉所（275 kV）は震度 6.4 → PGA 0.88 g → $P_{\mathrm{out}} = 0.445$、$u = 0.210 < 0.445$ で停止（DS3）。川口町五丁目変電所は PGA 1.14 g → 0.703、$u = 0.538$ で停止。

鉄塔の直列系と津波fragility.line_fail

$$p_{\mathrm{tower}} = \Phi\!\left(\frac{\ln(\mathrm{PGA}/12)}{0.9}\right),\qquad n = \max\!\left(\frac{\ell}{0.35\,\mathrm{km}},\,1\right),\qquad p_{\ell} = 1 - (1 - p_{\mathrm{tower}})^{n}$$
ℓ線路長 [km]。0.35 km 間隔で鉄塔が並ぶとみなす1−(1−p)^nn 基すべてが生き残る確率の補集合 = どれか 1 基でも倒れる確率（直列系）12 g1 基の倒壊中央値。地震動単独の倒壊は 1995・2011・2016・2018 で観測ゼロなので大きく置いた仮定

なぜ直列か。1 基倒れれば回線は止まる。長い線路ほど基数が増え、同じ PGA でも止まりやすい。2 回線以上は片方が残る可能性を 0.5 倍で表す。津波は浸水域内の基数を 5 と仮定し、浸水深ランク別の 1 基あたり確率から同じ式で求める。

例。PGA 0.6 g、$\ell = 20$ km → $p_{\mathrm{tower}} = 4.4\times10^{-4}$、$n = 57$ → $p_\ell = 1-(1-4.4\times10^{-4})^{57} = $ 0.025。
トレースの手: 尾鷲賀田線（77 kV）は浸水深ランク 6 → 停止確率 0.92、$u = 0.29$ で停止。

停止率曲線からの停止期間（逆変換サンプリング）fragility.generator_state

内閣府 2025 と同じ「震度階級ごとに、発災後 t 日に止まっている火力の割合 $f_c(t)$」の表を使う。各発電機の停止期間を、この割合と矛盾しないように 1 回の乱数で決める。

$$u \sim U(0,1),\qquad \tau \;=\; \sup\{\,t : u < f_c(t)\,\},\qquad \text{発電機は } t < \tau \text{ の間停止}$$
f_c(t)非増加。6弱・6強なら 3 週間 0.90、1 か月 0.23、5 週 0.06、6 週 0τ停止期間 [日]。表の点の間は線形補間

なぜこれで整合するか。任意の $t$ で「$\tau > t$ である発電機の割合」$= P(u < f_c(t)) = f_c(t)$。つまり全機の停止期間を集めると、どの時刻でも表の停止率がそのまま再現される。累積分布関数の逆関数から乱数を作る「逆変換法」そのもの。

例: 6強の火力。$u = 0.5$ なら $f_c(t) > 0.5$ なのは 3 週間まで（0.90）で、1 か月で 0.23 に落ちる → 補間で $\tau \approx 25$ 日。$u = 0.95$ なら初日から $f_c = 0.90 < u$ → $\tau = 0$（止まらない）。
トレースの手: 川越火力 3,053 MW は震度 6.6（7）→ 7 の曲線は 11 か月まで 1.0 → $\tau = 351.7$ 日。

需給・周波数・系統崩壊montecarlo._blackout

$$\frac{2H}{f_0}\,\frac{df}{dt} \;=\; P_{\mathrm{gen}} - P_{\mathrm{load}}\ [\mathrm{pu}]\qquad\text{（集約 swing 方程式）}$$ $$\delta_z \;=\; 1 - \min\!\left(1,\ \frac{G_z + T_z}{L_z}\right),\qquad \delta_z > 0.25 \;\Rightarrow\; \text{エリア } z \text{ 全停}$$
H慣性定数 [s]。回転機に蓄えた運動エネルギー ÷ 定格。系統全体で 4 s 程度f₀定格周波数 60 Hz（西日本）G_z, T_z, L_zエリアの生存供給力、連系線の受電上限、残存需要 [MW]0.25周波数低下リレー（UFLS）の段階遮断で吸収できる不足の上限として置いた仮定。較正スイープで 15/25/35% を比較

なぜ周波数が落ちるか。発電が需要に足りない分は、回転機の運動エネルギーを取り崩して賄われ、回転が遅くなる = 周波数が下がる。$H = 4$ s、不足 20% なら $df/dt = -0.2\times60/8 = $ −1.5 Hz/s。1 秒で 58.5 Hz。UFLS は 1 秒以内に段階的に負荷を切って止めるが、間に合わないと発電機の低周波数保護が働き全停する（北海道 2018: 46.13 Hz）。本モデルは動的に解かず、この式の帰結を「不足率のしきい値」で代理する。

トレースの手: 中部エリア: 残存需要 15.2 GW、生存供給力 5.7 GW、連系線 4.6 GW → $\delta = 1 - (5.7+4.6)/15.2 = $ 0.32 > 0.25 → 系統崩壊。中国エリア: $1-(6.3+9.0)/7.9 < 0$ → 0 → 維持。復電はサイトごとに対数正規（中央値 24 時間）。

DC 潮流cascade._dc_flows

交流の有効電力は $P_{ij} = \dfrac{V_iV_j}{X_{ij}}\sin(\theta_i-\theta_j)$。電圧を 1 pu、角度差を小さいとして $\sin\theta\approx\theta$、抵抗を無視すると一次式になる。

$$P_{ij} \approx \frac{\theta_i - \theta_j}{x_{ij}},\qquad B\,\theta = P,\qquad B_{ii} = \sum_{j} \frac{1}{x_{ij}},\quad B_{ij} = -\frac{1}{x_{ij}}$$ $$\text{基準母線 } \theta_{\mathrm{ref}} = 0 \text{ を除いて解く。注入 } P \text{ を MW で与えれば } f_{ij} = b_{ij}(\theta_i-\theta_j)\ [\mathrm{MW}]$$
x_ij枝のリアクタンス [pu, 100 MVA 基準]。線路は x_ohm/km × 長さ ÷ 回線数 ÷ (kV²/100)Bグラフのラプラシアンを 1/x で重み付けした行列。成分ごとに 1 つ特異なので基準母線を 1 つ落とすP_i母線の注入 = 発電 − 供給負荷。成分内で合計ゼロ

なぜラプラシアンか。キルヒホッフの電流則「各母線で流入 = 流出」を全母線で書くと $B\theta = P$ になる。抵抗網のオームの法則と同じ形で、$\theta$ が電位、$1/x$ がコンダクタンス。単位の罠: $P$ を MW で与えると $\theta$ も MW スケールになり、潮流は $b\,\Delta\theta$ そのもの。ここで ×100 を重ねると潮流が 100 倍になる（実際にやったバグ。1 手ずつ表示で発覚）。

例（3 母線ループ）。母線 1 に +90、3 に −90。直通 1–3 は $x=0.1$、迂回 1–2–3 は $x=0.2$。$B$ を解くと $\theta_1-\theta_3 = 6$ → 直通 $6/0.1 = 60$ MW、迂回 $6/0.2 = 30$ MW。
トレースの手: 反復 1「過負荷 45 本、最大 409%」。77 kV 線に 382 MW（緊急定格 117 MW）。

過負荷連鎖と LODFcascade.evaluate（反復）

$$|f_{ij}| > \gamma\,S_{ij},\quad \gamma = 1.25 \;\Rightarrow\; \text{枝を停止}\qquad f'_{l} \;=\; f_l + \mathrm{LODF}_{l,k}\,f_k \quad(\text{枝 } k \text{ 停止後の枝 } l)$$ $$\mathrm{LODF}_{l,k} \;=\; \frac{\mathrm{PTDF}_{l,k}}{1 - \mathrm{PTDF}_{k,k}}\qquad(\text{橋では分母が 0 で定義できない})$$
S_ij熱容量 [MVA]。理論値（√3·V·I）に較正係数。基底で既に超える枝は基底潮流 ×1.3 を緊急定格にするγ緊急定格倍率。短時間なら定格の 1.25 倍まで流せるとみなすPTDFある枝で 1 MW 送ったときに各枝に現れる潮流（感度）。DC では行列 1 つで固定

なぜ連鎖するか。枝が落ちると同じ注入を残りの枝で運ぶので、迂回路の潮流が跳ね上がる（板書 10 の図で直通が落ちると迂回路が 30→90 MW）。それが定格を超えれば保護リレー（過電流・距離）が次の枝を切る。本モデルは上位 3 本ずつ切って解き直し、最大 8 回で打ち切る。実装は LODF を使わず毎回 $B\theta=P$ を解き直す（同値だが単純）。

モンテカルロと期待停電日数montecarlo.Simulator.run

$$\bar S_i(t) = \frac1N\sum_{s=1}^N \frac{S_i^{(s)}(t)}{L_i},\qquad P_{\mathrm{out}}(i,t) = \frac1N\sum_s \mathbb 1\big[\text{受電不可}^{(s)}(i,t)\big],\qquad E[T_i] = \int_0^{90}\big(1-\bar\phi_i(t)\big)\,dt$$ $$\text{標準誤差 } \sqrt{\frac{p(1-p)}{N}}\ \Rightarrow\ p=0.3,\ N=200 \text{ で } \pm 0.032$$

ポテンシャル法potential.potential_index

$$w_{ij} = -\ln(1-p_{ij}) + \tfrac12\big[-\ln(1-p_i) - \ln(1-p_j)\big],\qquad d_i = \min_{\text{電源} g}\ \mathrm{dist}_w(g \to i)$$ $$S^{\mathrm{path}}_i = e^{-d_i}\sqrt{1-p_i},\qquad A^{\mathrm{sup}}_i = \min\!\left(1, \frac{\sum_{B(i,80\mathrm{km})} \bar P_g(1-p_g)}{\sum_{B(i,80\mathrm{km})} L_j}\right),\qquad P^{\mathrm{pot}}_{\mathrm{out}}(i) = 1 - S^{\mathrm{path}}_i\,A^{\mathrm{sup}}_i$$
−ln(1−p)「生存確率の対数」の符号を変えたもの。経路上の要素がすべて生き残る確率は積なので、対数を取ると和になり最短路問題になるd_iDijkstra で全母線一括。電源自身の停止確率も重みに入れるA^sup半径 80 km の生存供給ポテンシャル ÷ 負荷

なぜ最短路か。$\prod(1-p) = \exp(\sum \ln(1-p))$。最大の生存確率を持つ経路 = 重み $-\ln(1-p)$ の最短路。乱数も潮流も使わず 0.8 秒。限界: 経路が長いと積が 0 に飽和し、冗長経路（別ルート）の恩恵を見ない。A との需要加重相関は 0.56。

例。経路上に $p = 0.1$ の変電所が 5 か所、$p = 0.02$ の線路が 4 本 → $d = 5\times0.105 + 4\times0.020 = 0.61$ → $S^{\mathrm{path}} = e^{-0.61} = 0.54$。$A^{\mathrm{sup}} = 0.8$ なら $P^{\mathrm{pot}} = 1 - 0.54\times0.8 = $ 0.57。

ビューアには無い（潮流を解かない別経路）。地図 Artifact の「ポテンシャル」図に対応。

復旧の資源勘定resources.ledger

$$\text{人・日} = \sum_{e} n_{\mathrm{crew}}\,\tau_e,\qquad \text{稼働人数}(t) = n_{\mathrm{crew}}\sum_e \mathbb 1[\,s_e \le t < c_e\,],\qquad \text{資材}_m = \sum_e q_{m}(\text{種別}_e)$$ $$\text{電源車}(t) = \frac{\sum_{i \in \text{上流孤立}(t)} L_i}{0.5\ \mathrm{MW}}\quad\text{vs}\quad \text{保有}\times(\text{応援}\ 2\ \text{倍, 2 日目〜})$$
n_crew1 班の人数(8 人・仮定)s_e, c_e, τ_eジョブの開始・完了・修理日数(板書 12)q_mジョブ種別ごとの資材原単位(主変圧器・遮断器・がいし・鉄塔・電線)。東北電力 2011 の被害数を桁の目安にした仮定

なぜ積み上げるか。復旧曲線は「班数・修理時間」の仮定の帰結であり、裏返せば「この曲線を実現するには何人・何台要るか」が出る。稼働人数が班数の上限に張り付いていれば人手が律速、主変圧器の需要が予備を超えていれば資材が律速、と読める。

例(west・N=20 平均)。ジョブ 357 件、延べ 121,725 人・日。ピーク稼働 中部 640 人/日(=80 班 × 8 人で上限)。主変圧器 122 台 vs 予備 28 台。電源車はピークで関西 1354 台が要り、保有+応援を 1 桁超える。
